download Metal

open it, sign in to the ai you already use, and your first bot is working a couple of minutes later. free for personal use, no account needed.

Metal releases on GitHub

Metal installers will appear on GitHub when published. You can build Metal from source.

what you need.

a computer
mac (macos 12+), windows 10 or 11, or ubuntu 24.04.
an ai
claude, chatgpt, gemini, grok or another ai you use. an api key or a local model works too.

first time? the two minute guide. comfortable with servers? run it on your own.

check a download.

every release lists each installer's sha-256 fingerprint in SHA256SUMS. yours should match exactly.

mac

shasum -a 256 ~/Downloads/Metal.dmg

windows (powershell)

Get-FileHash $HOME\Downloads\Metal-setup.exe -Algorithm SHA256

linux

sha256sum ~/Downloads/Metal-amd64.deb
