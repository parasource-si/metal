what is an ai agent, in plain english?

an ai agent does the steps you would otherwise do yourself. give it a goal and suitable tools.

by the Metal team · checked 12 november 2026 · how we made this

it can read the material, act, see what happened and choose the next step. a chatbot tells you how to rename 200 files. an agent renames them. that's the whole difference, and also the risk.

watch one small job instead of learning the jargon

turn the folder you keep avoiding into a reading index. each document gets a subject and a pointer back to its source.

the agent finds the files, reads them and groups them. an unrelated file or one it cannot open belongs in the result as a gap.

the failure to fear isn't a crash. it's a confident index that silently skipped half the folder.

look at the tools behind the chat box

ask which steps you still have to do yourself. a chatbot can explain how to make the index. an agent with suitable tools can inspect the files and make it.

you might text either one. some chat products also have tools. the interface alone does not decide the difference.

the agent versus chatbot comparison goes further. for now, ask: can it reach the material and put the result where i need it?

give it four things before it starts

tell it what finished looks like. 'help me get organised' leaves almost every decision open. try this brief instead.

  • goal: make a reading index
  • material: use this exact folder
  • boundary: leave originals alone and report unreadable files
  • result: group source names by subject in the chat

now you can compare the index with the folder. if a source is missing, ask why. keep the first result small enough to read in a few minutes.

where dusk fits

keep a bot that remembers the job for next time. dusk is a desktop app for a small team you text like teammates. each bot has its own job and memory; you choose its name and ai.1

dusk has no model of its own. it runs vendors' official command-line apps where your bots live. your chosen ai does the thinking.12

drop files into chat or use attach files. results appear there and live in the bot's folder or your chosen project folder.2 start with a folder. don't hand it your inbox on day one.

access is one choice; repetition is another

a useful first job can live inside one folder. add an app when the task needs it, then look at the actions its connection gives the bot.

the mcp guide explains one way apps connect to tools. every extra permission should have a job to do.

in dusk, a routine repeats a job you describe once. local routines stop when the app closes or the computer sleeps.3 scheduled ai tasks covers hosting. a finished reading index may never need a weekly schedule.

read the result beside the source

a source name beside each claim makes the review quicker. compare dates, names and claims with the originals before passing the work on. a busy tool log tells you little about whether the answer is right.

keep the job small and the access narrow. when a run goes well, give it the next useful task.

before trying accounts or computer control, read the safety guide.

your first agent job should be small enough that you can spot a wrong answer.

try it in 2 minutes

  1. choose two short files you can share
  2. ask for one sentence about each, with its source name
  3. tell it to leave originals alone
  4. compare the answer with both files

a first job you can review in minutes

  • the material is small and you know where it came from
  • the result has a clear shape
  • original files stay untouched
  • missing inputs must appear as gaps

mistakes people make

asking it to organise your whole life

choose one folder and one finished result.

trusting the answer because tools ran

compare the sources it used with the material you gave it.

questions

what are people actually using ai agents for?

index documents, compare two files or review new entries in a tracker. start with inputs you know, then compare the result with those sources.

does an ai agent have to run all day?

no, one job is enough. recurring work needs a schedule and a computer or hosted setup running when it is due.

is an ai agent the same as a bot?

bot is the broader word. look at a particular bot’s tools, access and instructions to understand what it can do.
