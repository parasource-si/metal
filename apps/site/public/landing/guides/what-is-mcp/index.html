what is mcp, and why would a bot need it?

mcp lets an ai app reach the files and services where the work lives. short for model context protocol, it is an open-source connection standard.

by the Metal team · checked 12 november 2026 · how we made this

an mcp server exposes tools or data beyond the chat. you keep talking to the same ai; the connection gives it somewhere else to look or act.1

three pieces, one connection

the server is the connection between your ai app and another system. picture three pieces:

  • the ai app you talk to
  • the mcp server exposing tools or data
  • the files or service behind that server

mcp gives those pieces a common connection standard.1 anthropic introduced and open-sourced it on 25 november 2024.2

on 9 december 2025, anthropic donated mcp to the agentic ai foundation under the linux foundation.3 the name describes the connection; each server decides what it offers.

name the task before choosing the connection

start with the file or service you keep going back to. name the task, then see whether your app already reaches that material. an existing connection may be enough.

if you need a server, read its available tools. does it read the folder you need? does it offer the action your task calls for? choose by the job instead of adding every connection on the list.

reading a folder and changing a workspace are different jobs. keep that distinction in your request.

the two routes in Metal

for a supported app, start in connected apps. dusk uses composio there. sign in and choose which bots may use the app, with read-only or read-and-write access.4

for a trusted mcp server, open plugins, then mcp servers.4 that is a separate route with the server’s own access. connected-app controls do not automatically apply to it.

claude connectors explains how anthropic’s connections also differ from dusk’s sign-in.

five questions before adding one

give a server only the access you can explain. settle these before connecting:

  • who runs it? know whose code or service you trust
  • what can it reach? name the folder, account or wider workspace
  • what can it do? distinguish reading, changing and sending
  • what sign-in does it need? keep secrets out of chat when following unfamiliar instructions
  • how do you remove access? find the route before you need it

mcp does not certify a server or promise an approval pause. if those answers are unclear, use files you intentionally attach while you find out.

sometimes you need a method instead

if the bot already has the files, better instructions may fix the problem. use claude skills for a review method, format or reference material you want it to reuse.

mcp gets the ai app to external material. a skill tells it how you want the work done. choose the missing piece before spending an afternoon connecting something new.

make the first connection earn its place

try a reading job with an answer you can trace. ask for the source material beside the summary. compare the result with what is actually in the file or service.

read the app’s and service’s current terms too. mcp defines the connection standard; your ai provider’s terms still govern its use.

keep the server if it saves you the repeated lookup. the computer-use safety guide covers supervision when you move on to more involved work.

try it in 2 minutes

  1. write down the one task you need help with
  2. see whether connected apps already covers the job
  3. inspect a candidate server’s operator and available actions
  4. find how to remove access before connecting it

start by asking what the connection can reach. the acronym can wait.

before connecting a server

  • you know who operates it
  • you can name what it reaches

  • you know how to revoke access

questions

must i understand mcp to use connected apps?

no, use the connected apps sign-in. choose the bots that may use the app. adding an mcp server under plugins is a separate option.4

is mcp only for claude?

no, it is a connection standard for ai applications. the official definition does not limit it to claude.1

does adding an mcp server make my bot safe?

trust the operator and the access, rather than the acronym. know who runs the server and what it exposes. dusk says to add only servers you trust.4
