claude scheduled tasks: which kind are you using?

get the brief while your laptop is still shut. current cowork schedules run remotely as of 12 november 2026.

by the Metal team · checked 12 november 2026 · how we made this

claude code also has cloud schedules, desktop local tasks and an open-session loop. they need different setups. find the kind you used first: changing laptop sleep settings won't fix a cloud job, while a local job still needs that laptop awake.

current cowork schedules keep going remotely

your current cowork schedule can run while you sleep. saved prompts run remotely on a schedule or on demand. pro, max, ultra, team and enterprise support them; free does not.1

manual setup offers hourly, daily, weekly, weekdays and manual. each run starts its own cowork session and can use connectors, skills and plugins.1

older tasks created before 6 october 2026 can still run locally. open yours to see where it lives. scheduled tasks cannot use linked personal finance accounts.1

claude code has three other meanings of schedule

pick the schedule that can reach your work. claude code offers cloud, desktop and loop, each with its own behaviour.234

  • code cloud schedules, formerly routines, package prompts, repositories and connectors
  • local tasks in the desktop app need the app open and computer awake
  • /loop repeats a prompt inside an open code session

loop needs the machine on and has a minimum interval of one minute.4 the code routines guide covers cloud setup and its separate limits.

match your plan to where you want to work

see which features your plan gives you on the phone. as of 12 november 2026, cowork web and mobile support pro, max, ultra and team. team access is beta.6

claude desktop supports macos, windows and linux beta on all paid plans. schedules support pro, max, ultra, team and enterprise.16

new pro, max and ultra cowork tasks run in the cloud. the local-only option went away on 6 october 2026.6 try the task with its source files before leaving it unattended.

ten jobs that have a reason to repeat

put the work that changes on a schedule. point these prompts at a connected app or a folder the task can read.

  1. monday: read new product briefs in the brief folder. list three open questions per brief.
  2. mornings: read new experiment results in the tracker. suggest one next test per result.
  3. friday: find conflicting dates in the current milestone sheet.
  4. weekdays: read new policy drafts in the review folder. explain one unclear clause per draft.
  5. sunday: read changed business-plan files. challenge one changed assumption.
  6. tuesday: read new interview notes. suggest one unanswered customer question.
  7. monthly: find active project constraints that need a fresh decision.
  8. thursday: read new pitch drafts. suggest a simpler opening for each.
  9. evenings: read the current study file. test me on vocabulary still marked for practice.
  10. wednesday: read new documents awaiting review. propose a short checklist for each.

name the source and output length. tell it what to do if files are missing. if nothing changed, ask for one quiet line.

diagnose before moving the job

find the failed step before rebuilding the setup. open the task's schedule, time zone and usage account. local jobs need the host and app awake. for a cloud job, look at the remote run.

in dusk, ask a named bot for a routine. its card shows upcoming runs; automations shows history. local dusk routines still need an awake host.5

provider terms and usage allowances follow you between schedulers. read current terms before unattended work. the scheduler comparison helps once you know which failure you need to fix.

if the job runs in the cloud, leave the laptop settings alone.

try it in 2 minutes

  1. open the task that missed a run
  2. identify cowork, code cloud, desktop local or loop
  3. read its next run and time zone; try opening its source
  4. run one small test before changing hosts

questions

can a scheduled task use my personal finance accounts?

no, not through scheduled tasks. anthropic excludes linked personal finance accounts as of 12 november 2026. access elsewhere in claude does not carry over.1

why are claude scheduled tasks not working when my laptop sleeps?

a local task needs that laptop. code desktop needs the app open and computer awake. current cowork and code cloud schedules run remotely; older cowork tasks may remain local.123

are claude code routines and scheduled tasks different?

code cloud routines changed names. as of 12 november 2026, they are cloud scheduled tasks. that does not make them cowork tasks or session loops.24
