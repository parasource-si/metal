claude plan vs api: compare the bill you will pay

already paying for max? you may already have the api credits you need. as of 12 november 2026, claude pro is $20/month, max $100 and ultra $200 before tax.

by the Metal team · checked 12 november 2026 · how we made this

sonnet 5.5 api costs $2 per million input units and $10 per million output units. add your actual usage, subtract applied credits, and compare the bill under the current access terms.

what the plan and api prices cover

put the included credits beside the monthly price. anthropic lists these prices before tax as of 12 november 2026.1

planpricewhat matters here
pro$20 billed monthlyannual billing costs $200 up front, shown as $17/month
max$100/month5x pro usage; $100 monthly api credits
ultra$200/month10x pro weekly usage; $200 monthly api credits

the $200 plan is now ultra. older comparisons may still call it max. pro, max and ultra include claude code plus the web, desktop and mobile apps.12

the api charges for incoming and outgoing text separately. rates per million text units on the same date:3

  • sonnet 5.5: $2 input, $10 output
  • opus 5.5: $4 input, $20 output

output costs more. pricing everything at the input rate makes your estimate look pleasantly wrong.

three invented bills, with the sums shown

see how a $3 api job becomes $36, then $72. these are invented workloads, not typical usage. the sums cover only the stated input and output, before credits and other charges.3

small sonnet workload.

1 million input units x $2 = $2
0.1 million output units x $10 = $1
$2 + $1 = $3

that's below pro's $20 price. pro still has its own usage limits.13

larger sonnet workload.

8 million input units x $2 = $16
2 million output units x $10 = $20
$16 + $20 = $36

now raw api use exceeds $20. find out whether the job fits pro's limits before assuming the plan is cheaper.3

the same amounts on opus.

8 million input units x $4 = $32
2 million output units x $20 = $40
$32 + $40 = $72

same text counts, different model, twice the subtotal.3 keep input and output separate, then apply credits and billing terms.

credits can change what you owe

your credits can cover the api bill before you pay another dollar. as of 12 november 2026, max lists $100 monthly api credits; ultra lists $200.

anthropic's support update of 7 october 2026 says max, ultra and team include monthly api credits. signed-in agent sdk and claude -p still draw from plan limits.4

keep four lines apart:

  • the plan payment
  • included credits
  • raw api usage
  • the balance beyond credits

use the credits the provider actually applied. already paying for max? those may cover the job. buying a plan just for this work? count its whole price.

read the sign-in terms before choosing

choose a route the provider lets you use before pricing it. as of 12 november 2026, anthropic describes sign-in to unmodified claude code. it restricts developers handling sign-ins and reserves usage-credit billing for certain third-party tools.56

read your provider's current terms. they don't rule on a particular app here. the sign-in overview explains the routes; the dated log shows which rule came first.

count hosting only when the job needs it

add hosting only when your laptop needs to be off. dusk's ai usage stays on your provider bill. personal use on your own computer is free. cloud plus costs $20/month; pro costs $50/month. that buys the computer; ai usage stays separate.7

put the machine in the always-on calculator and other costs in the agent cost guide.

try it in 2 minutes

  1. open your provider's usage and billing records
  2. note the model, input, output and credits applied
  3. compare the full monthly cost with the plan you would actually buy

already paying for max? open the credits balance before buying another route.

mistakes people make

charging all text at the cheaper input rate

count output separately. its rate is higher in these examples.

adding a raw api bill after credits already covered it

use the balance actually due after applied credits.

assuming a $20 workload fits the $20 plan

read the plan limits. dollars do not map to a fixed text allowance.

quick checklist

  • the rates match the model i intend to use
  • input and output have separate amounts
  • credits appear only once in the calculation
  • the access method fits the provider's current terms
  • hosting and tax appear where they apply

questions

is claude max cheaper than the api?

sometimes, depending on usage and credits. as of 12 november 2026, max costs $100/month with $100 monthly api credits. compare your real bill, not an invented text allowance.1

does claude code need api-key billing?

not always. as of 12 november 2026, anthropic includes claude code with pro, max and ultra. api-key access is another route. the method and its terms decide billing.25

what should i measure before choosing?

record input and output separately. note the model and credits actually applied. for plan sign-in, inspect the provider's usage limits. there is no fixed price for one unit of agent work.
