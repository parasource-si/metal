is openclaw safe enough for your accounts?

openclaw's power comes with an upkeep job: yours. it can reach files and accounts, so start with a small reading task and limited access.

by the Metal team · checked 12 november 2026 · how we made this

as of 12 november 2026, github lists 722 published security advisories.1 use the affected versions and fixes to judge your install. that historical count alone won't tell you how many flaws remain.

what the advisory numbers tell you

your installed version matters more than the headline number. as of 12 november 2026, github lists 722 published advisories.1

  • critical: 14
  • high: 249
  • medium: 390
  • low: 69
  • first publication: 31 january 20261

the history includes one-click remote code execution through stolen sign-in access. february to april brought gateway privilege-escalation and sandbox-escape reports.1

find your version in each affected range, then apply its fix. the total alone tells you neither whether you are exposed nor whether your machine was compromised.

the malicious skills audit is a separate problem

read the skill before giving it your accounts. koi audited 2,857 clawhub skills and found 341 malicious ones. the hacker news reported that audit on 2 february 2026.2

a skill can cause trouble even when the agent is patched. read its instructions and scripts. leave it out if you cannot explain why it needs a command or secret.

those figures describe one audit, rather than today's whole catalog.

give the security work its due

openclaw has added scanning and brought in outside auditors. it says it added skill scanning with virustotal and nvidia and completed a trail of bits audit.

keep following current advisories and updating your own machine. scanning and audits help you assess the work; they cannot vouch for every skill you add.

if you want someone else to maintain it, compare the responsibilities in openclaw alternatives.

a smaller first job for any agent

make the first mistake cheap. use a separate machine or a workspace without private files. connect one account, read only for a summary. leave payments, publishing and broad file access out.

compare the answer with the sources it names. add access when the next job needs it. connected accounts still reach beyond a separate computer.

the computer-use safety guide covers watching and stopping the work.

how to set a boundary in Metal

in dusk, a read-only bot can bring you the summary without changing the account. app access is off, read only, or read and write per bot. dusk blocks read-only changes before they reach the app.3

sending uses its own setting.4 ordinary edits, such as labels or page changes, can happen without asking. keep the first job read only; require confirmation if you later permit edits.

add trusted servers under plugins, mcp servers. the mcp explainer covers that connection.

if you cannot explain what a skill runs, leave it out of the first setup.

try it in 2 minutes

  1. find the version you run
  2. open an advisory and compare its affected versions
  3. remove one add-on you cannot explain
  4. give the first reading task only read access

before connecting an important account

  • you know your installed version and its relevant fixes
  • you can explain each skill you added
  • the first job has only the access it needs
  • you know how to stop it and revoke its app access

mistakes people make

reading the advisory total as current open flaws

compare affected versions and fixes. the count alone cannot judge your installation.

trusting a popular skill without reading it

read its commands and access requests. skip anything you cannot explain.

thinking a separate machine protects connected accounts

it limits local files in reach. the account permissions still need their own limits.

questions

is openclaw safe for non-technical users?

take on only the upkeep you understand. start with a small reading job. get help before adding important accounts if versions, permissions or add-on code are unfamiliar.

does 722 advisories mean 722 open bugs?

no, it is a historical published count. that total comes from 12 november 2026. check affected versions and fixes to judge your install.1

are all clawhub skills malicious?

koi found 341 malicious skills among 2,857 examined. that was the audit reported on 2 february 2026, rather than a rate for today's whole catalog.2
