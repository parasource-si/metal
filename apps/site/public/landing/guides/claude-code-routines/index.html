claude code routines are now called scheduled tasks

your code review can run while the laptop is shut. claude code routines are now called cloud scheduled tasks.

by the Metal team · checked 12 november 2026 · how we made this

save a prompt, repositories and connectors once, then trigger it by schedule, api call or github event. as of 12 november 2026, anthropic hosts them in research preview. local desktop tasks and /loop still need an awake computer.123

save the setup, not just the words

save the project context once instead of pasting it every morning. a cloud task keeps three choices together:1

  • prompt: what to do
  • repositories: the project files
  • connectors: the systems it can reach

that suits a recurring code review. a household reminder probably needs less setup. pick the job before learning another scheduler.

choose a frequency the scheduler can keep

the fastest recurring cloud task runs hourly. as of 12 november 2026, the shortest recurring interval is one hour.1

  • create one at claude.ai/code/routines or with /schedule
  • available on pro, max, ultra, team and enterprise
  • research preview; runs use your plan allowance
  • account ceiling: 100 scheduled runs per hour
  • run now, api fires and rerunning one-off tasks: 30 per hour per task

those ceilings count different things. 100 account runs does not give one recurring task a one-minute interval. the old name survives in the setup address.

three timers, three different homes

the machine matters more than the timer. choose where the source files and tools live.

  • cloud scheduled tasks: anthropic runs them, including with your laptop closed.1
  • local tasks in the desktop app: use your machine's files and tools. the app must stay open and the computer awake.2
  • /loop: repeats inside an open claude code session. its minimum interval is one minute; the machine stays on.3

a local folder and a cloud repository are different inputs. the laptop-closed guide explains that boundary. before following a tutorial, find out which timer it means, or if it covers claude's main app instead.

cowork has its own scheduled tasks

cowork can work through the night too. cowork and the new claude experience run saved prompts remotely, even while your computer sleeps.

older tasks created before 6 october 2026 that ran on your computer stay local.4 the claude scheduled tasks guide covers that split. open an older task and see where it runs before closing the laptop.

dusk routines start with a message

tell the bot what should repeat and read its card. dusk returns the schedule and next runs. edit, pause or undo it there. automations shows a calendar and run history.5

a connected-app event can start a routine too. local dusk routines stop while the app closes or the computer sleeps. missed by less than 12 hours? they run once when you return. older runs skip. dusk cloud runs them on time.5

scheduled ai tasks compares those homes. decide whether a delayed result is still useful before paying for an always-on machine.

fix the job before repeating it

a schedule repeats mistakes just as faithfully as useful work. name the input, result destination and reason to stay quiet. run the underlying job once. open its source references, then fill in missing context.

in dusk, begin reading jobs with read-only app access.6 for later edits, include "ask me before you change anything". ordinary app edits do not automatically wait for approval.7

try it in 2 minutes

  1. choose a project and one reading job
  2. write the source and the result you want
  3. try it once without changes
  4. choose cloud or local before adding the schedule

if the tutorial says "leave the session open", it is not describing a cloud task.

mistakes people make

following an old routines tutorial blindly

look for cloud tasks, desktop tasks or /loop in its setup steps.

reading the account ceiling as a task frequency

cloud tasks still have a one-hour minimum.

scheduling a job that cannot find its files

test the source access once before repeating it.

quick checklist

  • i know which machine runs the job
  • the files and tools are available there
  • the frequency fits this scheduler's limits
  • one trial returned a result i could trace to the source
  • the job says when to stay quiet

questions

will claude code routines work with my laptop closed?

cloud tasks do. local ones need the machine. desktop tasks need an open app and awake computer. /loop needs the open local session too.123

can i run a cloud scheduled task every minute?

not a recurring cloud task. its minimum is one hour. /loop can repeat every minute inside an open local session.13

do i need cron to make a dusk routine?

no. say the job and timing. read the schedule card, then edit or pause it if needed.5
