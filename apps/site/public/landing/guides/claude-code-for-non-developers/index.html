claude code for non-developers: start with one folder

that folder of notes can become a useful outline without you learning to code. give claude code a few files you understand and a clear job.

by the Metal team · checked 12 november 2026 · how we made this

dusk runs the official command-line app while you text a bot. prefer anthropic's own route without a terminal? cowork is another option, now becoming part of claude.123

pick the notes you keep putting off

turn the reading packet into decisions you can use. start with personal project notes or a planning document. ask for a summary and leave the originals alone.

a useful first request names:

  • the files to read
  • what the answer should contain
  • what must stay untouched
  • where to leave unanswered questions

"organise my computer" is a lot to hand over on day one. the agent introduction explains the trade-off.

make one bot for the job

give the bot the job you wish you had finished yesterday. choose new bot, then a name, shape, colour and plain-word job. pick its ai.

dusk has no model of its own. it runs vendors' official command-line apps where your bots live; you sign in yourself.8

read your provider's current terms before choosing sign-in. dusk also accepts an api key or local model if another route fits better.1

give it only the files it needs

drop the packet in chat and ask what it could read. attach files accepts documents, spreadsheets, pictures and screenshots.5

request an outline with a source beside each point and unanswered questions at the end. compare it with the originals.

output appears in chat and lives in the bot's folder or a project folder you choose. use copies for the first try.

watch and correct the first run

steer it while it works. replies stream in and a line shows each tool. send another message when it takes the wrong turn. cmd . on mac, or ctrl . on windows and linux, stops it. answer its questions with allow or deny cards.4

keep ask for approval on for commands and file edits.6 this file exercise needs no mail, chat or payment connections.

give corrections it can use

"you missed the decision in paragraph three" beats "try again". point to the source. if the tone is wrong, name the change you want.

dusk remembers what you tell it. read or edit notes in memory, or turn memory off.7

keep lasting preferences apart from one-off facts. "short paragraphs" can travel; one document's deadline should not become a rule. skills can hold a way of working you want to reuse.

when claude’s own app fits better

try cowork if you want claude's own file-work interface. as of 12 november 2026, anthropic includes it in paid plans without a terminal. it now describes cowork and chat as one claude, bringing in cowork for file work.23

read the pricing guide for that route. choose dusk when you want named bots, separate conversations and an ai per bot.

use the same small packet to see which way of working fits you.

try it in 2 minutes

  1. attach two short notes you already understand
  2. ask: "summarise the decisions, with a source beside each; change no files"
  3. trace each decision back to the notes
  4. give one precise correction

if you cannot tell whether the answer is right, shrink the job.

quick checklist

  • i can name the files the bot should read
  • i know what a correct answer would include
  • the request says what must stay untouched
  • missing evidence stays a question

mistakes people make

starting with a folder you cannot review

use two files whose contents you know.

approving an unfamiliar command to keep things moving

stop and ask what it does before allowing it.

saving one deadline as a lasting preference

keep task facts tied to their source; reserve memory rules for habits.

questions

can i use claude code without a terminal?

yes, with a different interface. dusk lets you text a bot running the official command-line app. anthropic offers cowork for knowledge work without a terminal.12

do i need to learn programming first?

no programming lesson needed for this exercise. ask it to read files and explain them. do not approve a command you cannot understand.

what should i try before giving it my inbox?

turn a small packet into an outline with references. choose non-sensitive files you understand, then compare the outline with them.
