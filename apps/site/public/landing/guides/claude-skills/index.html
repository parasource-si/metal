claude skills for people who do not write code

stop explaining your review method every time you open a chat. a claude skill keeps the instructions, scripts and reference material in a folder that loads when needed.

by the Metal team · checked 12 november 2026 · how we made this

it gives claude a repeatable way to work. as of 12 november 2026, anthropic lists skills across all plans, including free, with code execution enabled.1

put a usable method in the folder

save the correction you are tired of making. a skill gives claude a repeatable method for a particular task, using instructions, scripts and resources in a folder.1

for a document review, that might mean:

  • your writing rules
  • an approved reference document
  • a list of things the finished document must contain

write steps you could follow yourself. "compare dates in the draft with the brief" gives it a job. "make it excellent" leaves it guessing.

give claude the folder once

your method goes in a zip; you do not need to build an app. on individual plans, the setup as of 12 november 2026 is:2

  1. open settings, then capabilities
  2. enable code execution and file creation
  3. open customize, then skills
  4. upload a zip of the skill folder

read its instructions and any scripts before enabling it, especially if someone else made the zip. start with a folder you understand.

work out which piece is missing

choose the piece that saves you repeating yourself.

  • skill: how to do the work, with its format and reference material
  • connector: the app data or actions the job needs
  • schedule: when to repeat it

anthropic’s connectors retrieve data and take actions in apps.3 claude connectors covers access; mcp explains the connection standard. the skill teaches the method; the connector gets it to the material.

make the first trial catch an error

give it a document with a mistake you already know about. a conflicting date, blank field or missing section makes a useful trial. ask for reasons beside each suggested change.

compare the answer with the document. did it flag the gap or fill it with a guess? that tells you more than asking the ai to grade itself.

use a short document without private material while you learn its habits. keep the method only if it catches the correction you built it for.

do not build a skill for a one-off problem

for a one-off request, just write the prompt. if the audience and purpose change every time, fresh instructions may take less work than maintaining a skill.

build the folder when the same rules and references keep coming back. it will not fix a vague brief or reach an unavailable account. keep the smaller approach when it works.

want a desktop helper instead? start with the non-developer guide. reusable instructions earn their keep when the work repeats.

keep a skill only if you can name the repeated correction it saves you.

try it in 2 minutes

  1. write three corrections you repeat on the same kind of document
  2. compare them with a skill folder you already have
  3. read that folder’s instructions and any scripts
  4. try its checklist on a short document you know well

what do you actually need?

the missing piecestart with
the same review method every timea skill
files or actions in another appa connector
the job should repeat at a set timea schedule
one unusual request with enough contexta prompt for that job

mistakes people make

uploading a zip without reading it

inspect the instructions and scripts before enabling the skill.

testing only perfect input

try a blank field or conflicting date and see whether the skill flags it.

questions

do i need a paid plan for skills?

no, free is on anthropic’s list. as of 12 november 2026, it lists free, pro, max, ultra, team and enterprise. enable code execution first.1

are skills and connectors the same?

no, one teaches a method; the other provides access. skills carry instructions and resources. connectors reach supported apps and actions.13

can i upload a skill without writing scripts?

yes, a script is not required. skills can contain instructions and resources too. upload a zip of the skill folder, using contents you understand.12

free on your own computer, with every feature. no account, no card.
