claude code from telegram, discord or slack

text your bot from the couch without turning slack into a remote terminal. a custom bridge needs someone to handle who can direct it, how approvals return and which computer stays on.

by the Metal team · checked 12 november 2026 · how we made this

anthropic’s remote control and dusk’s own chats offer other routes.12 most people asking for this just want to text their bot from the couch. that part needs no bridge.

what do you want the chat app to do?

decide whether you want to talk to the bot or hear from it. “claude code in slack” can mean very different jobs:

  • control a session by sending a slack message
  • let a bot read team discussion
  • post a finished report into a channel

a posting action handles the last job. it does not give channel members control of the session. decide who may issue instructions before building that route. skip that and anyone in #general can tell your agent to run commands.

a bridge needs an owner

a weekend bridge project with your github token in it is how accounts get emptied. someone has to own more than the message box:

  • who: which person or channel may issue requests?
  • context: does a message continue a job or start another?
  • approval: where do questions arrive, and how do answers return?
  • uptime: which computer keeps the session running?
  • failure: how do you spot a lost connection?

if you can’t answer those five questions, don’t build it.

remote control keeps the session on your machine

your phone is a window, not the computer doing the work. as of 12 november 2026, remote control connects claude.ai/code or claude’s ios and android app to your local session.1

the computer must stay on with claude running. this route does not use telegram, discord or slack. the phone guide compares where the session lives.

dusk gives each bot its own conversation

want claude code in your pocket? text the bot from your phone. pair once by scanning a code. paired with your computer, it works while that computer is on. paired with dusk cloud, it works with the laptop shut.3

dusk keeps named bots with jobs, chats, memory and an ai choice for each. it runs official ai command-line apps where the bots live.2

you talk in dusk. each bot has a conversation you can come back to, without another team-chat channel to maintain.

slack can receive the result

put the finished report where your team already reads. dusk’s slack actions include message search and sending. prepare the result in the bot’s chat, then name its channel. see the slack integration.4

sends ask first unless you allow a daily amount. careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.8

reading jobs can stay read only. other app edits do not automatically ask; tell a writer “ask me before you change anything”.5

discord’s action list covers account and server membership, with no message-posting action as of 12 november 2026. the discord connection handles different jobs from slack.6

choose the route you can keep running

use the smallest route that answers the actual need. remote control suits a window into your running local session. dusk suits its own bot conversations and app connections.

a custom bridge makes sense when that chat entry point matters enough to maintain it. decide who will fix it after a broken connection.

use the computer safety guide to limit what the session can reach. if the yes/no prompt doesn’t reach you, the bridge is broken. fix that first.

before building a bridge, ask if you only wanted the finished report in slack.

try it in 2 minutes

  1. choose control, reading or posting as the job
  2. write down who may direct the session
  3. choose where approval questions should arrive
  4. name the machine that must stay awake

mistakes people make

treating a post action as session control

verify the incoming-instruction route separately.

letting every channel member direct the bot

define the people allowed to give instructions before connecting it.

questions

is there an official telegram bridge for claude code?

we do not know of one. anthropic’s published phone route is remote control.1

can i use a slack post to control a Metal bot?

you chat with the bot in dusk. slack events can start a routine and arrive at once. the bot can post back, but slack does not become its chat interface.247

does the discord connection include posting messages?

the checked action list does not include it. that is the discord catalog as of 12 november 2026.6
