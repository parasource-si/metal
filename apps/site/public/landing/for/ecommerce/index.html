an ai agent for the shop work between orders

answer "where's my order?" with the right order open. a store bot reads shopify records and customer email, then prepares replies from the details it finds.

by the Metal team · checked 12 november 2026 · how we made this

it can also review abandoned checkouts and suggest product copy. shopify needs your own composio project key and sign-in configuration; managed sign-in isn't available. start with store access read only.

the routines

weekly abandoned-checkout review

every monday at 9, read last week's abandoned shopify checkouts available to this connection. list returned references, dates and item details here. group repeated items without guessing why people left. flag missing fields and incomplete results separately from no abandoned checkouts. never contact customers, send recovery messages, create discounts or change the store.

read only is enough. use the abandoned-checkout listing action. shopify setup covers its extra connection requirements.

customer replies grounded in the order

each weekday at 11, read new customer questions in store gmail. use an email's order number to find that exact shopify order. draft a reply here from its details and the store-policy file in our project folder. ask about uncertain matches. never promise delivery dates, refunds or replacements without confirmation.

both apps can stay read only. drafts return here. saving drafts in gmail needs separate drafting access.

product copy from the current specifications

every thursday at 3, read the product-review list and specification files in our store project folder. find the listed shopify products and compare their descriptions with those files. suggest clearer copy here and list unanswered buyer questions. skip products with no new review notes. never invent materials, performance claims or reviews. never publish or change listings.

keep a small, current review list. use the folder as the recurring input, so each run checks products that need attention.

shopify has an extra setup step

get shopify connected before promising yourself a monday report. it needs your own composio project key and sign-in configuration. follow the shopify setup.

while that's being set up, attach product notes and try a copy draft. you can see whether the writing helps before connecting the store.

give the customer an answer you can stand behind

a wrong delivery promise buys you another angry email tomorrow. ask the bot for the order's current status and any missing details. keep arrival dates as questions until someone can confirm them.

put your refund and replacement policy in a readable file. requests outside it come back to you. the bot does the lookup and prepares the reply; you decide what to promise.

keep refunds and publishing with you

keep the busywork moving while store changes stay with you. read-only shopify access covers these jobs and blocks store edits. if a later job needs writes, include "ask me before you change anything". app edits don't all ask automatically.

running a shop is work use and needs a license. cloud pro includes one for one person.3 see pricing. your ai provider bills usage separately.

try it in 2 minutes

  1. attach one product specification file
  2. ask for a clearer description from that file alone
  3. match each size, material and claim to the file
  4. keep the proposed copy in chat until you choose to publish

use the order number. two customers with the same name should never get each other's reply.

before sending a customer reply

  • the order number matches the email
  • the reply follows the current written store policy
  • delivery, refund and replacement promises have confirmation
  • private details belong to this customer

mistakes people make

matching customers by similar names

use the exact order number from the email. ask when the match is uncertain.

turning an order status into a delivery guarantee

quote what the record says. leave arrival promises for someone who can confirm them.

reviewing the same products forever

maintain a current review list and skip products without new notes.

questions

does this work for a non-technical store owner?

the jobs use ordinary messages; shopify setup takes more work. it requires your own composio project and sign-in configuration. use attached notes and email first if that is not ready.

can it reply to customers without touching orders?

it can prepare replies while store access stays read only. keep drafts in dusk chat and copy them yourself. saving gmail drafts needs the specific drafting actions.

will it automatically issue refunds?

these routines do not. they report questions for your decision. keep shopify read only to prevent store changes.
