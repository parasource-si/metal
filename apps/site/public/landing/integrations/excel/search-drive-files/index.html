Metal/integrations/excel

find the excel workbook before reading its cells

get the right workbook without opening every file named final. give the bot a name fragment or project phrase.

by the Metal team · checked 12 november 2026 · how we made this

it searches onedrive, including shared files if you ask, and lists matching excel files. pick the copy you want, then ask it to read the cells. the search itself opens and changes nothing.

what it does

you remember the project. the bot finds the file. a search can match names, file details or content. name another drive if your default isn't the right one.

  • include shared files, or search only your own folders
  • ask for xlsx and xlsm if other files clutter the results
  • choose a workbook before asking a separate excel action to read its cells

when you would use it

  • find an old installation budget when only the project name rings a bell
  • track down a shared costing workbook outside your own folders
  • compare matching xlsx and xlsm files before choosing the report source

try it

paste this into a chat with your bot

on the first of each month at 9, search my onedrive for excel files with "timesheet" in the name. include files shared with me. keep going until onedrive has no more results. list names and available file details here. flag files for the current month and any unclear matches. never open or change workbooks.
when
the 1st of each month at 9:00
needs
excel connected; read only is enough for this search

what comes back looks like this (an example)

timesheet workbooks
- timesheets-2026.xlsx
- timesheets-november-contractors.xlsm: matches this month
which copy should i read?

set it up

  1. connect excel in Connected apps. give this finder read only access.
  2. give a name fragment and say whether shared files belong in the search.
  3. name the file types you want. tell it to follow the results to the end before reporting no matches.
  4. pick the right copy before requesting cell values. Edit changes the routine search.

what it needs from you

inputrequiredwhat it is
queryyesSearch query text to find items (e.g., filename like 'roster.xlsx' or partial name).
topnoMaximum number of items to return.
scopenoSearch scope: 'drive' searches entire drive including items shared with current user; 'root' searches within user's drive hierarchy only.
drive_idnoID of the drive to search (use 'me' for the user's default drive in delegated auth, or a specific drive ID).
skip_tokennoOpaque pagination token from a previous response's next_link URL ($skiptoken value).
file_extensionsnoOptional list of file extensions to filter results (e.g., ['.xlsx', '.xlsm']).

from composio's catalog for Excel (action EXCEL_SEARCH_FILES, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Search Drive Files as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Excel asks for to run it: Files.Read, Files.ReadWrite, Files.Read.All, Files.ReadWrite.All.

where it stops

  • look in onedrive for this job. local folders and google drive need a different search.
  • keep going after an empty result. excel filters each batch separately. the next batch may hold your workbook.

try it in 2 minutes

  1. connect excel with read only access
  2. ask: "find my november timesheet workbooks, including shared files"
  3. compare the names and file details before picking one

final-final.xlsx still needs a project and a month. filenames get optimistic.

mistakes people make

opening the first similar filename

ask which folder and project it belongs to before reading figures.

calling an empty result the end

ask it to keep going until onedrive has no further results, even after an empty batch.

questions

can it find an excel file someone shared with me?

yes, if your account can see it. ask to include shared files. say "only my own files" for a narrower search.

does this search inside spreadsheet rows?

find the workbook, then ask about its rows. content can match the file search, but a separate action reads the table or cells.
