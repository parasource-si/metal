Metal/integrations/gmail

ask ai to send the gmail draft you already checked

finish the proposal in gmail, then release it when the client says yes. the bot sends the saved draft to its saved recipients, including cc and bcc.

by the Metal team · checked 12 november 2026 · how we made this

it uses the text exactly as it stands. open that copy before allowing the send; edits in chat need a separate draft update.

where it helps

  • send a proposal you finished in gmail once the customer confirms the deadline
  • send the venue confirmation after checking its booking reference
  • release an introduction after both people agree

the short version

write it once in gmail. send that exact copy from chat. use a draft you wrote yourself or one a bot prepared earlier. ask it to list drafts and open the match.

the saved to, cc and bcc decide who receives it. update a wrong address or sentence separately, then read the saved email. sending asks by default unless you allow a daily amount.

step by step

  1. connect gmail and give the bot read and write access.
  2. allow listing and opening drafts alongside sending. it needs to show you the saved email.
  3. set Sending on your behalf to Ask every time. test with a draft addressed to yourself.
  4. read the saved copy, then allow the send. Pause stops the daily ready-draft review.

send this to your bot

paste this into a chat with your bot

every weekday at 4, list gmail drafts whose subject starts with "ready:". show each draft's to, cc, bcc and full text here. ask before each send. send only the copies i allow, exactly as saved. if several drafts fit, ask which i mean. never rewrite a draft or send one i have not seen.
when
weekdays at 16:00
needs
gmail with read and write; sending set to ask every time

what comes back looks like this (an example)

1 ready draft
subject: ready: orchard quay venue confirmation
to: nina@orchardquay.example
cc: none
bcc: none

we confirm the room booking for the agreed date. please keep the entrance clear for our equipment.

send this saved copy?

what can go wrong

  • careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.
  • save your correction into the draft. a correction in chat alone leaves the gmail copy unchanged.
  • same subject, different drafts. ask the bot to show both and let you choose.

permissions and asking first

Metal counts Send Draft as a send: it reaches people or moves money, so it waits for your Allow (unless you set a daily amount, or the bot is on Full access with no sending rule, which lets it send up to 25 a day). a bot you allow only to read can never call it.

the permissions Gmail asks for to run it: https://mail.google.com/, gmail.compose, gmail.modify.

from composio's catalog for Gmail (action GMAIL_SEND_DRAFT, read 12 november 20264). your bot fills these in from what you tell it.

read the draft in gmail if anything changed since your last preview.

try it in 2 minutes

  1. set gmail sending to ask every time
  2. ask the bot to open a draft addressed to you
  3. read its full text, to, cc and bcc
  4. allow that saved copy to send

quick checklist

  • the account and draft match your intent
  • to, cc and bcc contain only intended recipients
  • the saved text includes your latest edits
  • sending asks every time

mistakes people make

fixing an address only in chat

ask for a draft update, then inspect the saved address.

leaving bcc out of the preview

show all three recipient lists. hidden recipients still receive the email.

questions

can it change the recipient when it sends the draft?

change it before the send. this action uses the saved recipient list. update the draft and read it again first.

how does it know which draft i mean?

name the subject and account. the bot lists drafts and opens the match. if two fit, ask it to show both.
