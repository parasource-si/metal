revise a gmail draft without starting over

say "shorter" instead of rewriting the email yourself. a bot can revise a saved gmail draft's wording, subject or recipients. it updates the draft without sending it.

by the Metal team · checked 12 november 2026 · how we made this

every edit rebuilds the message, so attachments need adding again. ask for a proposed revision if you want to read it before the saved draft changes.

what it does

keep the proposal attached while you cut the waffle. the bot replaces the draft's message. recipients, subject and body stay as they were unless you ask to change them. files need adding again, even for a one-word edit.

have it retrieve the existing attachments first and stop if one is missing. a shorter email still needs the proposal it promises.

when you would use it

  • cut a long proposal. keep the pricing pdf attached while shortening the wording.
  • fix the introduction before sending. correct its recipient and subject on the saved draft.
  • use the confirmed delivery date. replace the tentative one without rewriting everything.
  • finish the sign-off. ask it to add your configured gmail signature.

try it

paste this into a chat with your bot

each wednesday at 3, find gmail drafts about kiln deliveries created or changed during the past week. show each recipient and subject, then propose a shorter body here. ask me before updating any draft.

keep its recipients and subject. retrieve and reattach every existing file; stop if one is unavailable. skip drafts that need no change. never send or edit unrelated drafts.
when
wednesdays at 15:00
needs
gmail read and write, limited to draft listing, updating and required file retrieval

what comes back looks like this (an example)

proposed revision for noor at willowquay ceramics

subject: kiln delivery
body: delivery is confirmed for thursday. handling notes attached.
file to keep: kiln-handling.pdf

read this version before it replaces the saved draft.

set it up

  1. allow draft edits. connect gmail with read and write, restricted to the needed actions.
  2. find the saved message. list drafts with full details, including recipient, subject and files.
  3. ask for the revision first. say which parts stay, and require every attachment again.
  4. open the saved result in gmail. look at the recipients and attachments, then try recurring edits. pause if it picks the wrong draft.

what it needs from you

inputrequiredwhat it is
draft_idyesThe ID of the draft to update.
ccnoCarbon Copy (CC) recipients' email addresses.
bccnoBlind Carbon Copy (BCC) recipients' email addresses.
bodynoEmail body content (plain text or HTML); is_html must be True if HTML.
is_htmlnoSet to True if body is already formatted HTML.
subjectnoEmail subject line.

from composio's catalog for Gmail (action GMAIL_UPDATE_DRAFT, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Update draft as a change: it alters something in Gmail, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Gmail asks for to run it: https://mail.google.com/, gmail.modify, gmail.compose.

where it stops

  • the files must go back in. keeping the recipient or subject does not preserve attachments.
  • show everyone on the email. ask for the full recipient list after the edit, including copies.

try it in 2 minutes

  1. choose one saved draft with an attachment
  2. ask for a shorter version, without saving
  3. require the same recipient, subject and files
  4. allow the edit, then inspect the attachment

open the file before admiring the shorter sentence.

mistakes people make

checking only the new wording

open the attachments too. replacing a draft does not keep them automatically.

editing the same old proposal every week

review new or changed drafts. skip anything that needs no revision.

questions

will old attachments survive a wording change?

only if the bot adds them again. tell it to stop if a file is missing.

can it change the draft without asking?

yes, if you allow draft updates. put a review step in the request; draft edits do not ask automatically.
