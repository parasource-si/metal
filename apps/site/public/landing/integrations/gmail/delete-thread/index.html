Metal/integrations/gmail

permanently delete one gmail conversation with ai

that old thread can take the signed attachment with it. delete thread removes every message in a gmail conversation immediately and permanently.

by the Metal team · checked 12 november 2026 · how we made this

it skips trash, so there is no undo. use it only for mail you want gone for good. sending approval does not hold deletion; tell the bot to ask before it removes anything.

what it does

read back to the first reply before saying goodbye. a search may match the last message, while the signed file sits further back. have the bot show the subject, people and message count, then open the whole conversation.

for an ordinary inbox clear-out, use trash. permanent deletion is for the conversation you have decided must go.

when you would use it

  • a secret sent by mistake: remove a thread containing a password or bank details after you decide it must go.
  • the wrong file: delete the named conversation after checking every reply.
  • an obsolete conversation: review it alone, instead of wiping a folder.

try it

paste this into a chat with your bot

every friday at 5, find gmail conversations labelled "to shred". show each subject, everyone in the conversation and its message count here. ask me before deleting anything. delete permanently only the conversations i choose. if i don't reply, delete nothing. leave every other conversation alone.
when
fridays at 17:00
needs
gmail read and write for this bot; keep the allowed actions narrow

what comes back looks like this (an example)

2 conversations labelled to shred
- old lease scan: you and vesna, 4 messages
- deposit bank details: you and the letting agent, 2 messages

which conversation should go forever?

set it up

  1. find it first. connect gmail read only while the bot searches.
  2. read the whole thread. ask for its subject, people and message count.
  3. allow deletion deliberately. enable read and write with only the needed actions. say "ask me before deleting anything".
  4. try one proposal. compare the people and message count with gmail. pause the friday review when you no longer need it.

what it needs from you

inputrequiredwhat it is
idyesID of the Thread to delete.

from composio's catalog for Gmail (action GMAIL_DELETE_THREAD, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Delete thread as a change: it alters something in Gmail, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Gmail asks for to run it: https://mail.google.com/.

where it stops

  • choose trash while you still have the choice. it is the route for mail you might need again. this action removes the entire conversation for good.
  • keep deletion out of everyday sorting. allow only the reads and deletion this job needs, rather than the full gmail action list.

if you hesitate, keep deletion disabled.

try it in 2 minutes

  1. ask the bot to find one conversation without changing it
  2. read its subject, people and message count
  3. open it in gmail and inspect older replies

quick checklist

  • this is the right account and conversation
  • i read every message, including older replies
  • i want permanent deletion, rather than trash
  • the routine asks before it deletes

mistakes people make

using permanent deletion for a tidy inbox

choose trash when you might want the mail back.

approving from the subject alone

read the whole conversation first.

questions

can i restore the thread from gmail trash?

no. there is no copy in trash. this action deletes permanently. choose the separate trash action if recovery matters.

does deleting a thread remove only my last reply?

it removes them all. have the bot read the whole conversation, including older replies, before you decide.
