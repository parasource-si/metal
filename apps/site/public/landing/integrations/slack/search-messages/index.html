Metal/integrations/slack

find the slack message behind a question

find the promise before you walk into the supplier call. give the bot a phrase, person, slack channel or date.

by the Metal team · checked 12 november 2026 · how we made this

it searches by relevance or time and gathers more results when needed. use the match to open the thread: a later reply may have changed the deal. searching leaves slack alone.

what it does

start with the phrase you half remember. add the channel, person or month if you know them. the bot returns matching wording with its author and time. ask for oldest first to trace the first mention.

then read the conversation. search and thread reading are separate actions, and later replies can turn a promising offer into a rejected one.

when you would use it

  • find the first proposal for a supplier discount
  • locate the missing-adapter message in the equipment channel
  • collect mentions of the old product name before a rename
  • trace a delivery promise inside a known date window

try it

paste this into a chat with your bot

each wednesday at 14:35, search #vendor-terms for freight surcharges mentioned in the previous seven days. show the matches oldest first here, with author, date and exact relevant words. read matching threads separately when replies could change the meaning. report failed reads. never post a reply or call a proposed price an agreed one.
when
wednesdays at 14:35
needs
slack with read only for message search and thread reading

what comes back looks like this (an example)

freight surcharge discussion
- ren, hollow pine supply, monday: proposed a winter surcharge
- leonie, tuesday: asked whether it covers returns
replies returned: still discussing it; no agreement found.

set it up

  1. connect slack and give the search bot read only.
  2. give a phrase plus a channel or person. see whether the first matches fit.
  3. choose relevance or date order. ask for more results if the first batch leaves gaps.
  4. schedule the recurring search and read its next runs on the routine card.

how Metal handles it

Metal counts Search messages as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Slack asks for to run it: search:read.

where it stops

  • the first batch may be incomplete. ask for all matches when the count matters.
  • connect the account that can see the conversation. search cannot reveal private messages outside its access.
  • a sleeping laptop cannot start the search. leave dusk running on an awake machine or use dusk cloud.

try it in 2 minutes

  1. connect slack with read only access
  2. ask for one phrase in a named channel during the last week
  3. open the matching thread before treating the message as an answer

the reply that changes everything is often one message below the search hit.

mistakes people make

quoting the proposal as the final price

read the replies. later messages may change or reject it.

asking for the oldest mention but accepting relevance order

say "oldest first" and compare the dates.

questions

can i search only messages from one person?

yes. name the person and the bot can narrow by sender. it can also narrow by channel and dates.

can it find the oldest mention instead of the best match?

yes, ask for oldest first. sorting by relevance can put a newer message at the top.

does searching slack tell me whether the question was answered?

follow the match into its thread. the replies tell you whether anyone answered the question.
