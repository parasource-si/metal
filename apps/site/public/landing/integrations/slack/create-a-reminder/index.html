Metal/integrations/slack

turn a request into a slack reminder

remember the samples before the courier arrives. tell the bot what slack should remind you to do and when.

by the Metal team · checked 12 november 2026 · how we made this

it can create a one-off or repeating reminder for your connected account. slack handles the repetition after that. reminder creation is a write, so ask for a preview and a pause if you want to approve the text and time first.

what it does

one weekly reminder needs one creation. slack can handle its repeating schedule after that. you do not need a bot to recreate it every friday.

text and time are required. use ordinary words such as “tomorrow at 2” or “every thursday at 2pm”.

reminding someone else depends on your connection. if that fails, the bot should tell you rather than quietly remind the wrong person.

when you would use it

  • beat the courier. remind yourself to bring the sample before pickup.
  • stop forgetting expenses. create one recurring personal reminder for your weekly claim.
  • keep a promise visible. save a nudge to follow up on the delivery you discussed.

try it

paste this into a chat with your bot

every friday at 16:00, read next week’s sample pickup events from my work google calendar. compare them with my existing slack reminders. for each pickup without a reminder, propose one for myself an hour before pickup. show the text and exact time here. ask me before creating anything. create only the reminders i choose. never remind another person or duplicate an existing reminder.
when
fridays at 16:00
needs
google calendar read only; slack read and write to list and create personal reminders

what comes back looks like this (an example)

proposed slack reminders

1. collect the frostmere samples, tuesday 13:15
2. collect the frostmere glaze kit, thursday 10:00

both reminders are for your connected account. create these?

set it up

  1. connect slack narrowly. allow read and write for the reminder job.
  2. write the actual nudge. include text, time, recipient and whether it repeats.
  3. try a personal reminder. ask for a preview if you want to approve the schedule first.
  4. open slack’s reminders. confirm the saved text, time and recipient before leaving the routine running.

from composio's catalog for Slack (action SLACK_CREATE_A_REMINDER, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Create a reminder as a change: it alters something in Slack, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Slack asks for to run it: reminders:write.

where it stops

  • another person may be out of reach. if slack refuses, the bot should report it instead of changing the recipient.
  • repeating creation means repeating duplicates. create a recurring slack reminder once; use routines for fresh pickups or other changing inputs.

try it in 2 minutes

  1. connect your slack account
  2. ask for a personal reminder in two minutes
  3. read the exact text and time
  4. confirm it appears in slack

a reminder should say what to do, not just the project name.

mistakes people make

recreating the same weekly reminder

make one repeating reminder instead.

assuming the recipient changed successfully

confirm who slack will remind before calling the job finished.

questions

can it remind a teammate instead of me?

usually not. only some slack connections can create reminders for other people. the bot should say when yours cannot.

do i need a dusk routine for every weekly reminder?

no. ask once for a repeating slack reminder. use a dusk routine when the items needing reminders change each week.
