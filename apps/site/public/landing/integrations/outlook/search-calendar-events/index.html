Metal/integrations/outlook

find the outlook appointment you can only partly remember

you remember the venue, not which saturday you booked it. a bot searches your outlook primary calendar and returns matching appointments.

by the Metal team · checked 12 november 2026 · how we made this

work and school accounts use microsoft search. personal accounts need start and end dates when that search is unavailable. give a short topic or attendee clue and get the dates back in chat.

search calendar events, in plain words

one distinctive word can get you back to the appointment. try a topic, venue or person. the bot returns matches from your primary calendar without changing them. shared and secondary calendars need a different action.

for personal accounts without microsoft search, give both ends of a date window. every word must match somewhere in the event’s title, preview, location or people. one or two words usually beat a long description.

a routine to copy

paste this into a chat with your bot

each saturday at 09:10, search my personal outlook primary calendar for "pottery" in the next thirty days.

- finish scanning the entire date window
- list matching titles, dates and locations here
- say if the scan remains unfinished

never edit, decline or respond to an event.
when
saturdays at 09:10
needs
outlook connected with read only; access to the personal account’s primary calendar

what comes back looks like this (an example)

pottery appointments in the next thirty days
wheel workshop: saturday, 10:00, ashby kiln
pottery glaze consultation: following wednesday, 16:00
searched the whole thirty-day window on the primary calendar.

good jobs for it

  • recover a workshop date. search by the workshop name you remember.
  • find a venue. give the place and dates for a personal-calendar scan.
  • locate a customer meeting. use an attendee clue before considering changes.
  • compare similar appointments. ask for candidates rather than a guessed winner.

before it runs

Metal counts Search calendar events as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Outlook asks for to run it: Calendars.Read, Calendars.ReadWrite.

how to start

  1. keep searches read only. connect outlook for this bot.
  2. choose the account. the appointment needs to be in its primary calendar.
  3. give the dates. try a focused topic and confirm a familiar result.
  4. review the scan note. then schedule it and edit the weekend time if needed.

limits worth knowing

  • personal scans need both dates. work and school microsoft search ignores those scan-window settings.
  • finish the personal-account date window. an empty batch can have matching appointments after it.
  • extra words can hide the meeting. every term must match in a personal-account scan.
  • use another route for shared and secondary calendars. this action reaches the primary calendar only.

try it in 2 minutes

  1. connect outlook with read only
  2. choose the account whose primary calendar holds the appointment
  3. give a topic plus start and end dates
  4. ask whether the whole search finished

if the meeting lives on a shared calendar, say that first. this search will not reach it.

mistakes people make

adding every detail you remember

start with one distinctive word. personal scans require every word to match.

calling the first empty batch "nothing"

finish the date window before drawing that conclusion.

questions

does it work with a personal microsoft account?

yes, with dates when microsoft search is unavailable. give start and end times and a short search phrase.

why did an empty search find something later?

the first batch may have had no matches. ask the bot to finish scanning the whole date window.

can it search all my shared calendars?

this action reaches only your primary calendar. use a separate approach for shared calendars.
