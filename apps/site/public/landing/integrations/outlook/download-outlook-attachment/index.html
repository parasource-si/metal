Metal/integrations/outlook

retrieve the actual file attached to an outlook email

get the delivery note out of the email before the van arrives. a bot can find an outlook message, list its attachments and download the file you name.

by the Metal team · checked 12 november 2026 · how we made this

give the copy a filename you will recognise next week. read-only outlook access is enough. this action needs an actual attached file; cloud links and embedded items need a different route.

download outlook attachment, in plain words

you name the email and file. the bot finds the rest. describe the sender, subject and attachment you want.

it finds the message, lists what's attached and saves the chosen file under a name you'll recognise. if two files look alike, ask it to show the choices before downloading.

a routine to copy

paste this into a chat with your bot

each friday at 13:15, search outlook for this week's delivery-note emails from beth at coldbrook fittings. list each message's attachments. download only actual pdf files and name the copies with their delivery references. return the files and subjects here. report links and embedded items as unsupported. never forward mail or move it to another folder.
when
fridays at 13:15
needs
outlook read only for finding messages, listing attachments and downloading files

what comes back looks like this (an example)

coldbrook fittings
- email: delivery cb-217 paperwork, from beth
- file: coldbrook-cb-217-note.pdf

cloud link skipped: not an attached file.

good jobs for it

  • delivery paperwork: get the supplier's attached note before a shipment arrives.
  • a print proof: retrieve the image attached to the customer's email.
  • signed forms: collect the file without forwarding the conversation.

before it runs

Metal counts Download Outlook attachment as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Outlook asks for to run it: Mail.Read.

how to start

  1. connect read only. that covers this outlook collection job.
  2. describe one file. give the sender or subject. ask the bot to find the email and list its attachments.
  3. resolve lookalikes. choose the right attachment and a useful filename.
  4. open the download. open one copy before scheduling collections. pause if unsupported items keep appearing.

limits worth knowing

  • a cloud link isn't a file attachment. links and embedded items can't download through this action.
  • similar names can hide different files. match the filename to its sender and subject before downloading.

the details it works from

inputrequiredwhat it is
file_nameyesThe desired filename for the downloaded attachment.
message_idyesThe unique identifier of the email message that contains the attachment to be downloaded.
attachment_idyesThe Microsoft Graph API attachment identifier (NOT the filename).

from composio's catalog for Outlook (action OUTLOOK_DOWNLOAD_OUTLOOK_ATTACHMENT, read 12 november 20264). your bot fills these in from what you tell it.

try it in 2 minutes

  1. name one email and the attachment you want
  2. ask the bot to list its attachments
  3. choose the file and a useful saved name
  4. open the downloaded copy

the sender and subject often matter more than "final.pdf".

mistakes people make

asking it to download a cloud link

list the attachments and look for a file, rather than a link.

trusting "final.pdf"

match it to the email, sender and other attachments first.

questions

can it download a cloud link attached to an email?

not through this action. it needs the attached file itself. a link or embedded item won't do.

why does it need to list attachments first?

so it chooses the right file. listing shows what the message actually carries, instead of guessing from a filename.
