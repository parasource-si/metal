put an agreed appointment on your outlook calendar with ai

put the agreed visit in outlook while the details are still fresh. give a bot the subject, start, end and time zone. it can add a location, guests or repeating dates.

by the Metal team · checked 12 november 2026 · how we made this

leave the calendar unnamed and it uses your main one. creation counts as a change, so ask to review the entry first; sending approval won't pause it.

create calendar event, in plain words

an agreed time needs an exact entry. give the title, start, end and time zone. the start must come before the end. name the calendar or it uses your main one.

  • add body text, location or categories when useful
  • choose busy, free or another availability status
  • give repeating dates a clear pattern
  • request the online-meeting option and teams for business provider for a teams link

a routine to copy

paste this into a chat with your bot

on the last tuesday of each month at 16:40, look in my outlook calendar named field visits for next month's stockroom inspection. propose it on the first thursday, 15:00 to 15:30, europe/paris, at the east stockroom. skip creation if it already exists. never fall back to my main calendar. show the title, full dates, location and empty guest list here. ask me before creating anything. after approval, create it and return the saved details. never add attendees.
when
last tuesday of the month at 16:40
needs
outlook connected with read and write for calendar listing, event reading and event creation

what comes back looks like this (an example)

proposal for field visits
stockroom inspection
3 december 2026, 15:00-15:30, europe/paris
east stockroom. no attendees.
add this to field visits?

good jobs for it

  • keep personal plans in the right place. name the calendar before creating the appointment.
  • make a site visit easy to find. include the street address and travel notes.
  • reserve agreed office hours. give the repeating pattern an end.
  • create the meeting people expect. request the teams online-meeting option.

before it runs

Metal counts Create Calendar Event as a change: it alters something in Outlook, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Outlook asks for to run it: Calendars.ReadWrite.

how to start

  1. connect outlook with read and write for the calendar actions this bot needs.
  2. ask it to list calendars. read the destination, start, end and time zone together.
  3. include 'ask me before creating anything', especially for guests or repeating dates.
  4. open the approved event in outlook. pause the routine if the inspection plan changes.

limits worth knowing

  • no calendar name means your main one. forbid that fallback when it would be wrong.
  • all-day entries need midnight dates in one time zone. don't mark a timed appointment all day.
  • three o'clock needs a place. give the time zone and read the local time in the preview.
  • creation doesn't check clashes. ask for a separate read of existing events first.

try it in 2 minutes

  1. ask which outlook calendars the bot can see
  2. name the destination, start, end and time zone
  3. request a proposal with no attendees
  4. approve it, then open the saved event

read back the full date as well as the weekday before you approve.

mistakes people make

leaving the destination unstated

name the calendar. otherwise the entry lands on your main one.

letting a monthly routine add duplicates

look for an existing inspection before proposing the next one.

before you create it

  • the calendar name matches
  • start, end and time zone are clear
  • the bot read existing events for clashes
  • guests, location and repeat pattern match the plan

questions

will it ask me before adding a meeting?

only if you ask it to. creation counts as a change. put the checkpoint in the message or routine.

can it create a teams meeting link?

yes, with the right options. ask for an online meeting using the teams for business provider.

can i choose how the time appears to others?

yes. name the availability status. busy, free, tentative and out of office are options. not every calendar entry needs to block time.
