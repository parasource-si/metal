Metal/integrations/outlook

send an outlook email with the details checked

get the final dispatch note to the customer without another round of copying. give the bot an outlook recipient, subject and text, plus files and any cc or bcc.

by the Metal team · checked 12 november 2026 · how we made this

it prepares a preview and sends after you allow it by default. you can also set a daily amount. this action sends immediately rather than saving a draft.

what it does

turn the agreed words and final file into a ready-to-send email. the bot needs a recipient, subject and body. it can attach one file or several; each needs content, a valid name and a file type.

a different from address needs send-as or send-on-behalf permission. typing an address grants nothing. use plain text unless formatting matters; the body and chosen format must match.

when you would use it

  • email an agreed delivery note to the warehouse address you name
  • send a workshop access letter with its final pdf
  • send a short internal notice to a fixed list
  • write a new supplier request as a new email, rather than pretending it belongs to an old thread

try it

paste this into a chat with your bot

every thursday at 10:10, read final dispatch notes added this week to my local dispatch folder. use the customer contact address in each note. skip any note without a final mark or a complete address. show each recipient, subject, full body and attachment name here.

wait for my approval before sending through outlook. save a sent-items copy and report the result. never replace recipients or use unfinished files. if a send result is unclear, ask me before trying again.
when
thursdays at 10:10
needs
outlook with read and write; access to the dispatch folder; sending set to ask every time

what comes back looks like this (an example)

dispatch email for review
- customer: rachel at rivermint ceramics
- to: address from the final dispatch note
- subject: dispatch note for the kiln shelves
- attachment: final-dispatch-note.pdf
show the full address and body before allowing this send.

set it up

  1. connect the outlook mailbox and give the dispatch bot read and write.
  2. set Sending on your behalf to Ask every time.
  3. give the recipient address and final file. ask to see every recipient, the body and attachment name.
  4. open the sent-items copy after the first send, then schedule the folder review.

what it needs from you

inputrequiredwhat it is
toyesThe primary recipient's email address(es).
bodyyesThe content of the email body as a plain string (plain text or HTML based on `is_html`).
subjectyesThe subject line of the email.
is_htmlnoSpecifies if the email body is HTML; `True` for HTML, `False` for plain text.
to_namenoThe display name of the primary recipient.
cc_emailsnoList of email addresses for CC recipients.

from composio's catalog for Outlook (action OUTLOOK_SEND_EMAIL, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Send email as a send: it reaches people or moves money, so it waits for your Allow (unless you set a daily amount, or the bot is on Full access with no sending rule, which lets it send up to 25 a day). a bot you allow only to read can never call it.

the permissions Outlook asks for to run it: Mail.Send.

where it stops

  • careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.
  • use the full recipient address. a name alone leaves room for a wrong match. a different from mailbox also needs permission.
  • an attachment can fail the send. empty files, missing names or missing file types need fixing first.

try it in 2 minutes

  1. connect outlook and set sending to ask every time
  2. ask for a short test email addressed to yourself
  3. read the full preview and allow that send
  4. open its sent-items copy

look in sent items before retrying. the customer may already have the first email.

mistakes people make

approving "attachment included" without a filename

ask for each filename and make sure it matches the final copy.

retrying when the send result is unclear

look in sent items and ask before sending again.

questions

can it send the same email to more than one person?

yes, including cc and bcc. primary recipients can use comma-separated addresses. cc and bcc have separate lists. inspect all three before allowing the send.

can it send from our shared mailbox?

only with the right mailbox permission. the action accepts a from address. the connected account still needs send-as or send-on-behalf access.
