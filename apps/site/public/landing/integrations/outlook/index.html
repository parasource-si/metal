an outlook bot for the mail around your meetings

walk into the renewal call knowing what you already promised. an outlook bot reads the calendar, finds related mail and hands you the last agreement, open questions and replies you owe.

by the Metal team · checked 12 november 2026 · how we made this

connect the mailbox and choose its ai. start read only for briefings. saved drafts need write access; sends ask by default unless your sending settings allow them.

what a bot can do in Outlook

get the email behind the calendar title. a meeting name rarely tells you the last agreement or the reply you owe. these actions put the appointment and its mail together, then let you draft or file when the job needs it.

actionMetal treats it aswhat you would use it for
Search Outlook messagesreadfind the mail about the customer or topic on your calendar
Get email messagereadread a matched email before using it in a briefing
List eventsreadsee which appointments need background today
List mail foldersreadidentify the folder you actually use for active projects
List mail folder messagesreadreview messages in a named project folder
Create a draft replysend: asks firstsave a reply to an existing message for you to inspect (it counts as a send, so it asks first)
Move message to folderchangefile a specific message into the folder you named
Send draftsend: asks firstsend a reviewed draft through the bot's sending controls

composio, the connection service behind Metal's apps, lists 333 Outlook actions (version 20261104_00, read 12 november 20265). Metal treats 139 as reads, 29 as sends and 165 as changes.

only actions starting with a read word (get, list, search) count as reads, so a read-only bot can't call the rest. a send reaches people or moves money, like add mail attachment, and waits for your Allow unless you set a daily amount.

connect Outlook

  1. open Connected apps in the sidebar.
  2. pick Outlook and sign in on Outlook's own page, so your password goes to them and never to a bot.
  3. choose which bots may use it, and whether each may only read or may also change things. your bookkeeper doesn't need your Outlook.
  4. ask in plain words. reading and drafting happen freely; sending asks you first.

tell the bot whether you mean work or personal mail.

choose outlook in connected apps, sign in through microsoft and enable it for your bot. label accounts clearly when you connect more than one.

start with reading access for briefings that need no saved drafts.

routines to copy

pick one gap in your day. these routines read current outlook mail and events. start with background notes before allowing saved replies or folder changes.

meeting background

every weekday at 8:30, read today's outlook events. for meetings about hushfen, find related mail. show the last agreed point, open questions and relevant message subjects here. say when the mail cannot answer something. never move events or write to anyone.

weekdays at 08:30 · short background notes for today's hushfen meetings

promises i made

every wednesday at 4, search this week's outlook replies for promises i made to send something later. read surrounding messages before deciding a follow-up is missing. quote each possible open promise here and mark uncertainty. never send reminders or edit mail.

wednesdays at 16:00 · possible open commitments, with the promise beside each

project folder review

every other friday at 10, read my outlook folder hushfen renewal. find messages that still need a reply. draft answers only where the mail supports them. ask before creating each draft reply and leave it unsent. list missing decisions here. never invent prices or move messages.

alternate fridays at 10:00 · unsent reply drafts after approval, plus missing decisions

what it asks you first

keep the reply ready while you decide what to say. a new email draft stays a draft. create draft reply counts as a send in dusk because its name includes reply. it follows sending controls even though it saves a draft.

  • sends show Allow and Deny by default
  • a daily amount can allow sends without individual approval

careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.

folder moves and calendar changes skip sending approval. keep a background reader read only. for supervised writes, say "ask me before you change anything".

what it cannot do

  • save outlook drafts while read only. it can read and report in chat. a saved draft needs write access.
  • read a mailbox you have not connected. signing in elsewhere does not connect it to dusk. connect each account you want it to use.
  • prepare an early brief on a sleeping computer. local routines need dusk open and the computer awake. cloud can run the job before you wake.

read the evidence before drafting the answer

bring the missing price decision into the meeting. if the mail only asks "can you confirm the price?", put that question in the brief. draft an answer once someone decides.

use the meeting prep brief to turn open questions into an agenda you can use.

keep the mailbox job small

start with one project, not your whole working life. outlook and gmail use different actions, folders and controls. do not assume every instruction maps across unchanged.

use a short date window or named folder first. if deciding which messages need you is the main pain, try email triage.

a useful brief can say "we still do not know". a confident guess costs more.

try it in 2 minutes

  1. connect outlook with read only access
  2. name one meeting on today's calendar
  3. ask for related mail and the last agreed point
  4. open the message behind its last-agreed point

mistakes people make

answering a question with a guessed price

require a supporting message or leave the price open.

assuming every saved draft uses the same controls

outlook draft replies count as sends in dusk. set sending to ask every time.

questions

can an outlook ai assistant read my calendar as well as email?

yes, if you allow both actions. outlook offers calendar listing and message search. name the account and project so the bot finds relevant mail.

will it reply to customers while i am away?

choose ask every time for sending. leave drafts unsent and grant no daily sending amount. the full-access setting needs its own sending rule too.

how do i use the assistant from my phone?

pair your phone to the bot's host. your computer must stay on with dusk running. pairing to dusk cloud works with your computer off.
