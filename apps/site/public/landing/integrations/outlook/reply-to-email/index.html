Metal/integrations/outlook

ask ai to reply to a specific outlook email

answer the delivery question with the certificate already attached. the bot replies to a specific outlook email with text you approve, files and optional cc or bcc.

by the Metal team · checked 12 november 2026 · how we made this

name the mailbox and original message so it lands in the right conversation. this action sends; ask for text here first if you still want to edit.

what it does

keep the answer attached to the email that prompted it. the bot finds and reads the exact message first. name the connected mailbox too, so a personal reply leaves from personal mail.

you can use plain text or html, attach files and name extra cc or bcc recipients. enable the html option for styled replies, or the recipient sees formatting tags as text.

when you would use it

  • answer a supplier’s delivery question with the confirmed address
  • attach an approved certificate to the customer email that requested it
  • decline a request using your short reason
  • confirm a correction in the buyer’s original email

try it

paste this into a chat with your bot

when outlook gets a delivery certificate request from liora@briarpost.example, read that email. find the matching final certificate in the linked 'approved delivery certificates' drive folder. show the reply text, source subject, file and recipients here. wait for my permission before replying from work mail. report the result. never use a draft certificate or add cc or bcc. if no approved file matches, stop and tell me.
when
when matching email arrives in the connected outlook mailbox
needs
outlook read and write for reading and replying; google drive read only; sending on ask every time

what comes back looks like this (an example)

reply awaiting approval
source: delivery certificate request from liora
attachment: briarpost-approved-certificate.pdf
cc and bcc: none

hello liora, the approved delivery certificate is attached. let me know if you need anything else for the booking.

set it up

  1. choose the correct outlook account and allow read and write for replies
  2. set sending on your behalf to ask every time
  3. ask for the source subject, proposed text, recipients and file here
  4. read and allow one reply before turning the request into a routine

what it needs from you

inputrequiredwhat it is
commentyesThe body content of the reply email.
message_idyesThe Microsoft Graph message ID (NOT an email address).
is_htmlnoWhether the comment body should be rendered as HTML (true) or plain text (false).
cc_emailsnoList of email addresses for CC recipients.
attachmentnoFile(s) to attach to the reply.
bcc_emailsnoList of email addresses for BCC recipients.

from composio's catalog for Outlook (action OUTLOOK_REPLY_EMAIL, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Reply to Email as a send: it reaches people or moves money, so it waits for your Allow (unless you set a daily amount, or the bot is on Full access with no sending rule, which lets it send up to 25 a day). a bot you allow only to read can never call it.

the permissions Outlook asks for to run it: Mail.ReadWrite, Mail.Send.

where it stops

  • careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.
  • use the subject to tell similar emails apart. the sender alone may match several conversations.
  • open the attachment in the preview. a polished reply can still carry yesterday’s certificate.
  • local bots stop during sleep or when dusk closes. dusk cloud runs routines on time.

work or personal? choose the mailbox before writing the first line.

try it in 2 minutes

  1. set outlook sending to ask every time
  2. find one email by sender and subject
  3. preview the reply and any files here
  4. read the preview, then allow the send

mistakes people make

choosing a reply by sender alone

include the original subject and date in the request.

pulling the final attachment from old chat messages

keep approved files in a connected folder and name it.

questions

can it leave the proposed reply here for me to edit?

yes, ask for text here first. keep the reply action for when the answer is ready to send.

can it add someone on cc?

yes, name the addresses. include cc and bcc in the preview before approving.

why did formatting tags appear in the email?

html needs its formatting option enabled. use plain text for a simple reply if you do not need styling.
