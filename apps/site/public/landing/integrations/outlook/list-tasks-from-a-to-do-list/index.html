review one microsoft to do list with your ai bot

see what needs doing before the week gets away from you. through outlook, a bot reads one microsoft to do list with task statuses and due dates.

by the Metal team · checked 12 november 2026 · how we made this

name the list and it finds it. you get a private checklist with undated work kept separate. long lists arrive in parts; ask it to reach the end.

where it helps

  • bring the household maintenance list back into view. see due dates without assigning new ones.
  • prepare for a planning call. read important tasks without marking them complete.
  • review what has not started. focus on one named project list.
  • decide which tasks need deadlines. collect the undated work without inventing dates.

the short version

get the deadlines and the forgotten tasks in one view. the bot can filter a list by status, importance or dates, then sort by due date or title. keep tasks without deadlines in their own group.

name the list and say whether to include completed work. for long lists, ask it to keep fetching until the end. that first batch can leave half your backlog out.

step by step

  1. connect outlook for reading. the task review needs read-only access.
  2. name the list. match the first few tasks to the one you meant.
  3. choose the scope. ask for the relevant statuses and keep undated work separate from late work.
  4. review one result. then set the weekly time. pause the routine when the opening checklist is retired.

what can go wrong

  • one list at a time. confirm its name before trusting the tasks in the summary.
  • long lists arrive in batches. the bot must read them all before calling the review complete.
  • filters leave things out. not-started tasks are only part of unfinished work. ask which statuses the bot included.
  • sleeping computers miss schedules. a run under 12 hours late runs once on return. older runs skip.

permissions and asking first

Metal counts List tasks from a To Do list as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Outlook asks for to run it: Tasks.Read, Tasks.ReadWrite.

try it in 2 minutes

  1. connect outlook with read-only access
  2. name one to do list
  3. ask for unfinished tasks and their due dates
  4. compare one result with the original list

ask what the filter left out. an empty short list can hide a busy long one.

mistakes people make

turning no date into a late task

give undated work its own group. decide its deadline yourself.

reviewing only tasks that have not started

include other unfinished statuses when you want the full outstanding list.

questions

will this mark tasks as read or completed?

this action only lists details. keep outlook read only and return the findings in dusk chat.

can i ask for only high-priority tasks?

yes. it can filter by importance, status and dates. ask it to state the filter with its answer.

can i start with just the list name?

yes. it looks up your lists by name, then reads the right one.
