Metal/integrations/notion

give new notion notes a proper home

get the field notes out of chat and into the project. a bot can create a notion page with a title and markdown, or start a blank page for later.

by the Metal team · checked 12 november 2026 · how we made this

give it an existing parent page or database. that's where the new note will live; this action can't make a top-level workspace page.

create notion page, in plain words

a new page needs a home, not just a title. give the bot the parent page or database and your note. it can start with markdown content or an empty page for later.

paste the parent's link when names repeat. otherwise the bot searches by name, and a familiar title can lead to the wrong project. this creates a fresh page rather than extending an existing one.

a routine to copy

paste this into a chat with your bot

each monday at 16:25, read field visit notes added today to the alderfinch restoration project folder. group notes from the same visit. look under the notion field visits parent for existing pages first.

show the title, parent and markdown for each new visit here. ask before creating its page, then return the page reference. never invent observations or repeat a visit already saved. if no new notes exist, create nothing.
when
mondays at 16:25
needs
read access to the field-notes folder; notion read and write for parent lookup and child-page creation

what comes back looks like this (an example)

new visit proposal

- title: alderfinch, north stair visit
- parent: field visits
- note: noemi noted ceiling staining. no moisture reading in the file.

the title, parent and text are ready for your review.

good jobs for it

  • file the site visit under its building. turn the note into a separate child page.
  • prepare for each interview. create a clearly titled blank page before the research session.
  • save the agreed workshop outline. give it a page without rewriting the project home.

before it runs

Metal counts Create Notion page as a change: it alters something in Notion, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Notion asks for to run it: insert_content.

how to start

  1. connect notion. allow search and page creation with read and write. give the bot the field-notes folder.
  2. confirm the parent. paste its link and ask where the new page will appear.
  3. preview a short note. read the title and markdown before allowing creation.
  4. open the first child page. verify placement. use edit on the routine card to change collection time.

limits worth knowing

  • the parent must exist and be accessible. this action cannot create a top-level workspace page.
  • names repeat. use the parent link when search could find more than one match.
  • a lost reply can hide a successful save. rapid creation can also hit conflicts. look for the page before retrying.

mistakes people make

naming the parent when two projects share it

paste the link. moving a misplaced note later is avoidable work.

retrying before checking notion

look for the first page. a lost reply does not mean creation failed.

questions

can it make a blank notion page?

yes. give it the title and parent without body text. fill the page later.

can it add a cover image?

yes, from a public image address. a private file on your computer is not a usable cover link.
