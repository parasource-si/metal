Metal/integrations/notion

add a batch of notes to an existing notion page

get the latest test notes under the heading where people will read them. a bot can add paragraphs, headings and lists to an existing notion page.

by the Metal team · checked 12 november 2026 · how we made this

append them at the bottom or insert them after a chosen block. keep long notes in shorter blocks: text can cut off, so open the saved section and read its final line.

add multiple content blocks (bulk, user-friendly), in plain words

keep the structure you already have. give the bot short notes with headings and bullets. it can add several supported block types together.

name the page and insertion point. the bot reads the page to find them. without a chosen position, notes go at the bottom. adding after a heading and nesting inside a block are different placements.

a routine to copy

paste this into a chat with your bot

every thursday at 12:15, read new glaze test files from the glaze tests folder in my project folder. prepare a short heading and bullets for the marlowfen pottery notion page. skip notes already on the page. read the page and show where the batch will go after test results. ask me before you change anything. after i agree, add the notes and read back the saved text, including its ending. never replace blocks or guess missing measurements.
when
thursdays at 12:15
needs
access to the glaze tests project folder; notion read and write for page reads and additions

good jobs for it

  • test results: add a short summary after the existing heading.
  • interview notes: append observations as a heading and bullets.
  • workshop planning: insert a section between two existing parts of the plan.

before it runs

Metal counts Add multiple content blocks (bulk, user-friendly) as a change: it alters something in Notion, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Notion asks for to run it: Insert content.

how to start

  1. connect the writer. allow notion read and write, limited to reading and adding blocks.
  2. choose the spot. link the page and name the heading the notes should follow.
  3. read the preview. ask for short notes and their position before any addition.
  4. read the saved ending. open notion and read the end of each paragraph. pause if repeated runs add the same notes.

limits worth knowing

  • 100 blocks fit in one request. split larger additions into separate batches and confirm each lands once.
  • choose after or inside. adding after a heading and nesting inside a block put the notes in different places.

mistakes people make

saying "add this to the page"

name the heading it should follow.

pasting one enormous paragraph

split the text into shorter blocks, then read the saved ending.

questions

can it insert text after a heading instead of at the bottom?

yes. name the heading. the bot reads the page, finds that spot and adds the notes after it.

does adding blocks erase the rest of the page?

it adds content rather than replacing it. name the position so the notes reach the people reading that section.
