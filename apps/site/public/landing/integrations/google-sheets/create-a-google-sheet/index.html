start a named google spreadsheet where it belongs

start the month with a spreadsheet you can find by name. a bot creates a blank google spreadsheet and places it in a drive folder.

by the Metal team · checked 12 november 2026 · how we made this

give it a title and destination link; exact folder names can return choices. creation and filing can succeed separately, so recover the existing file after a failed move. ask for review before this write.

what it does

start a fresh file when the old one carries too much history. this action creates a spreadsheet, not a new tab. a title is optional, but leaving it out gives you a default name.

folder names must match exactly. several matches return choices; no match returns an error. a folder link removes the naming guess. if filing fails after creation, recover the existing file before trying again.

when you would use it

  • separate a grant period. give the new ledger its own name and location.
  • start workshop feedback cleanly. create a blank file in the confirmed workshop folder.
  • leave old exhibition data behind. make a fresh planning file rather than copying last year's rows.
  • prepare an expense tracker. create the file now; add rows through a separate task.

try it

paste this into a chat with your bot

on the first weekday of each month at 09:20, read the monthly tracker plan in the tallowmere guild expenses folder. use the current month's approved entry and skip it if that entry already links to a spreadsheet.

propose a title with the month and the destination folder. ask me before creating anything. return the file and whether folder placement succeeded. if filing fails, report the file you already made. never populate cells, share it or create another copy during recovery.
when
first weekday of the month at 09:20
needs
access to the monthly tracker plan; google sheets read and write with permission to create in the chosen folder

monthly spreadsheet for leah

file exists. no second copy created; cells remain empty.

set it up

  1. allow file creation. connect google sheets with read and write for this bot.
  2. give the name and destination. if folder names repeat, choose the match or paste its link.
  3. put the pause in your request. tell the bot to show the title and folder before creating anything.
  4. open the file in drive. confirm its folder. pause the routine while recovering from a successful create and failed move.

what it needs from you

inputrequiredwhat it is
titlenoThe title for the new Google Sheet.
folder_idnoGoogle Drive folder ID where the spreadsheet should be created.
folder_namenoGoogle Drive folder name where the spreadsheet should be created.

from composio's catalog for Google Sheets (action GOOGLESHEETS_CREATE_GOOGLE_SHEET1, read 12 november 20264). your bot fills these in from what you tell it.

how Metal handles it

Metal counts Create a Google Sheet as a change: it alters something in Google Sheets, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Sheets asks for to run it: spreadsheets, drive.file, drive.

where it stops

  • build on the blank file next. headers, values, formulas and validation need other actions.
  • partial names don't pick a folder. exact names can return choices or no match.
  • recover the file after a failed move. creation may already have succeeded; find that spreadsheet before making another.
  • local schedules need an awake machine. misses under 12 hours run once when you return; older ones skip. dusk cloud runs on time.

try it in 2 minutes

  1. choose a clear spreadsheet title
  2. paste its destination folder link
  3. ask to review both before creation
  4. open the result and confirm where it landed

ask for two outcomes: file creation and folder placement. one success message can hide half a job.

mistakes people make

retrying after a failed folder move

look for the spreadsheet already created. recover that file before making another.

expecting a ready-to-use tracker

creation gives you a blank file. request headers and values as a separate step.

questions

does this create a new file or a tab?

a new spreadsheet file. copying a tab into another existing spreadsheet uses a different action.

can i tell it the folder name?

yes, use the exact name. multiple matches return choices. a folder link gives a clearer destination.

should i retry if it says the folder move failed?

find the spreadsheet first. creation may have succeeded. repeating the whole job can leave an unwanted duplicate.
