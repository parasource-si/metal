Metal/integrations/google sheets

ask about the values in a specific google sheets range

get the figures for your decision without digging through the workbook. name the file, tab and cells.

by the Metal team · checked 12 november 2026 · how we made this

the bot can read displayed figures, raw calculated values or formulas from that range. dusk labels this lookup as a write, so allow read and write and limit the bot to this retrieval action.

get spreadsheet values, in plain words

get the number, or find out how the sheet got it. choose what your question needs. paste the sheet link and name the tab and cells, such as 'cost review, a1 to d12'.

  • displayed values are the default, including currency and date formatting
  • raw calculated values suit arithmetic
  • formulas show how the sheet gets its answer

for dates, choose readable dates or raw numbers.

a routine to copy

paste this into a chat with your bot

every tuesday at 14:05, read a1:d12 on the cost review tab in the linked lunecrest print sheet. use raw calculated values to compare paper and binding costs. name the range beside the result here. show blanks separately from zero. never update cells or reorder rows. ask before reading beyond that range.
when
tuesdays at 14:05
needs
google sheets read and write, limited to get spreadsheet values

what comes back looks like this (an example)

lunecrest print, cost review a1:d12
paper: 180
binding: 95
difference: 85
blank delivery cost excluded. no cells changed.

good jobs for it

  • read a quoted price table without editing its source
  • explain formulas in a small costing range
  • compare a monthly summary without bringing in the whole workbook

before it runs

Metal counts Get spreadsheet values as a change: it alters something in Google Sheets, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Sheets asks for to run it: drive, drive.readonly, drive.file, spreadsheets.

give it the lookup, keep the editing tools out. allow this retrieval action only. reading a range needs no sorting or cell updates.

how to start

  1. connect sheets with read and write, allowing only this lookup action
  2. paste the file link and name the tab and exact cells
  3. ask for figures or formulas to match your question
  4. compare one result with the sheet, then edit the schedule card if needed

limits worth knowing

  • copy the tab name from the sheet. a spelling mismatch can stop the lookup.
  • huge ranges can fail. ask the bot to read a few hundred rows at a time.
  • use calculated values to do the maths. formulas show the workings; readable dates save you from puzzling over raw date numbers.

try it in 2 minutes

  1. paste the spreadsheet link
  2. name one tab and a small range
  3. ask for raw figures or formulas
  4. compare one returned cell with the sheet

include the column headings. 180 means little until you know what it pays for.

mistakes people make

treating an empty cost as zero

tell the bot to list blanks separately and leave them out of totals.

doing arithmetic on displayed currency text

ask for raw calculated values first.

questions

can it show formulas instead of the displayed totals?

yes, ask for formulas. ask for calculated values instead when you want to compare the resulting figures.

why is read-only access refusing a cell lookup?

dusk classifies this lookup as a change. give read and write access, then restrict it to this action. that keeps cell edits out.
