Metal/integrations/google sheets

find the google spreadsheet before opening its rows

the supplier sent the sheet. now the link is buried. a bot finds accessible google spreadsheets by name, content, dates or sharing status.

by the Metal team · checked 12 november 2026 · how we made this

it returns candidate files without changing cells. name searches start at the beginning of filenames, so give it the opening words or ask for a broader match when you only remember the middle.

search spreadsheets, in plain words

start with the bit of the filename you remember. name mode matches from the beginning. you can also find starred files, shared files or spreadsheets changed after a date.

content search covers names and descriptions too. ask where the word matched before assuming it came from a cell. have the bot gather the full result list. already have the link? use it and skip the hunt.

a routine to copy

paste this into a chat with your bot

every other thursday at 09:50, find google spreadsheets shared with me whose names begin "brackenport supplier".

- include shared drives
- finish reading all results
- return candidate names and file references here
- say if the shared-drive search is incomplete

never edit cells or export files. if names are ambiguous, leave the choice to me.
when
alternate thursdays at 09:50
needs
google sheets connected with read only; allow only spreadsheet search

what comes back looks like this (an example)

brackenport supplier candidates
- brackenport supplier rates - west
- brackenport supplier contacts
2 file references ready to open.

good jobs for it

  • recover supplier prices. find a shared sheet after losing the email with its link.
  • resume planning. collect starred spreadsheets changed since the project restarted.
  • find a project’s trackers. search filenames beginning with its project code.
  • search beyond the title. use a venue clue when you forget the spreadsheet name.

before it runs

Metal counts Search Spreadsheets as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Google Sheets asks for to run it: drive, drive.appdata, drive.file, drive.meet.readonly.

how to start

  1. keep the lookup read only. connect google sheets for this bot.
  2. allow search only. limit its app actions to spreadsheet search.
  3. try the name’s beginning. if that misses, try a content clue.
  4. open the closest candidate. once it finds the right files, schedule the search and update the prefix as the project changes.

limits worth knowing

  • a content match can come from the title. read the cells separately before claiming a row contains your term.
  • name a shared drive when a familiar file is missing. searches across shared drives can be incomplete; an empty list is not a full inventory.
  • trash stays out by default. ask to include it when recovering a discarded tracker.

the details it works from

inputrequiredwhat it is
querynoSearch query to filter spreadsheets.
order_bynoSort order (comma-separated list for multi-field sorting).
page_tokennoToken for retrieving the next page of results.
max_resultsnoMaximum number of spreadsheets to return (1-1000).
search_typenoHow to search: 'name' searches filenames only (prefix matching from the START of filenames), 'content' uses fullText search which searches file content, name, description, and metadata (Google Drive API limitation: cannot search content exclusively without also matching filenames), 'both' explicitly
starred_onlynoWhether to return only starred spreadsheets.

from composio's catalog for Google Sheets (action GOOGLESHEETS_SEARCH_SPREADSHEETS, read 12 november 20264). your bot fills these in from what you tell it.

try it in 2 minutes

  1. connect google sheets with read only
  2. ask for filenames beginning with a familiar project name
  3. request all candidates and any search gaps
  4. choose the file before asking about its cells

if you remember only the middle of the name, say that. a prefix search will miss it.

mistakes people make

assuming content means cell contents only

ask where the word matched. a title or description can cause the result.

searching again when you already have the link

give the bot the link and move on to the range you need.

questions

why does a word in the middle of the filename miss?

name mode starts at the beginning. ask the bot to search anywhere in the filename instead.

does this read every row too?

no, it finds spreadsheet files. choose one, then ask to read the relevant cells with a separate action.
