set basic filter, in plain words

show the rows your team needs right now. give the spreadsheet link, tab and columns. describe the condition in ordinary words, such as applications without a reviewer. the bot sets the filter.

for a private report, ask it to read values and list matches in chat. that leaves everyone else's sheet view alone.

paste this into a chat with your bot

on alternate mondays at 10:55, inspect the applications table in my linked rosehollow bursary sheet. propose a basic filter for rows whose reviewer field is empty. show the tab, range and condition here. ask me before setting it. after i agree, set the filter and report it here. never delete hidden rows or edit applicant details.

before it runs

Metal counts Set Basic Filter as a change: it alters something in Google Sheets, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Sheets asks for to run it: spreadsheets, drive.file, drive.

how to start

  1. connect google sheets. allow table reading and setting a basic filter with read and write.
  2. link the spreadsheet and name the tab and table. explain which values should count as empty.
  3. ask for the proposed range and condition. keep "ask me before setting it" in the routine.
  4. look at the visible rows after the change. Pause if the selection rules change before the next run.

limits worth knowing

  • the filter belongs to the sheet. it is not a private report inside dusk chat.
  • name the table and the rows you want. the spreadsheet link alone leaves the bot guessing.
  • the filter stays after the bot leaves. turn it off in sheets when the review ends.

mistakes people make

asking for a private list but allowing a sheet change

request matching rows in chat when other people should keep their view.

including the wrong table in the range

match the tab and first and last columns to your table before setting the filter.

questions

does filtering delete rows that do not match?

the rows stay in the file. the filter hides non-matching rows. keep deletion actions out of this bot's allowance.

can i get a list without changing the sheet filter?

yes, ask for matches in chat. the bot needs a value-reading action for that. set basic filter changes the spreadsheet itself.
