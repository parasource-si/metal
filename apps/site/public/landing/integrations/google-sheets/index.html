what a bot can do in Google Sheets

composio, the connection service behind Metal's apps, lists 58 Google Sheets actions (version 20261101_00, read 12 november 20264). Metal treats 16 as reads, 0 as sends and 42 as changes.

only actions starting with a read word (get, list, search) count as reads, so a read-only bot can't call the rest. a send reaches people or moves money, and waits for your Allow unless you set a daily amount.

connect Google Sheets

  1. open Connected apps in the sidebar.
  2. pick Google Sheets and sign in on Google Sheets's own page, so your password goes to them and never to a bot.
  3. choose which bots may use it, and whether each may only read or may also change things. your bookkeeper doesn't need your Google Sheets.
  4. ask in plain words. reading and drafting happen freely; sending asks you first.

give the bot the tab and the actions it needs.

in connected apps, sign in to google sheets and allow your spreadsheet bot to use it. google receives the sign-in. paste the spreadsheet reference into chat and name the tab.

for controlled updates, allow only the actions the job needs. don't grant the entire catalog.

routines to copy

the bot needs column meanings, not just a file link. say what counts as an exception and where changes may go. each message below names the result you should get.

stock exceptions

each monday at 9, read the inventory tab in my stock sheet. compare available units with each row's reorder level. list items below that level here, with row numbers. leave values and row order alone. if none are below it, say so in one line.

mondays at 09:00 · a list of stock exceptions with their row numbers

intake rows

every weekday at 5, read new request files added today to the intake requests project folder. compare them with the intake sheet to skip existing requests. prepare new rows using the sheet's column names. show the rows here and wait for me to approve the append. append only the rows i choose. never overwrite existing requests or guess missing details.

weekdays at 17:00 · new rows for your review, then an append only after your yes

weekly chart check

every friday at 2, read the weekly totals table in my sales sheet. report its covered dates and any empty weeks. propose a chart from only that table. wait for me to choose it before creating it. leave the source values alone.

fridays at 14:00 · a date coverage check and a chart to approve

what it asks you first

keep cell changes tied to the range you chose. updates, sorting and charts do not automatically wait for an approval card. put "ask me before you change anything" in the editing job.

leave find and replace off a reading bot's exact action list. dusk counts it as a read even though it changes cells. some lookup-like actions count as writes. choose actions by what they do, rather than how their names sound.

what it cannot do

  • a reading bot needs an exact action list here. updates, appends and formatting need writes. find and replace is the exception: dusk counts it as a read, so leave it off.
  • "clean this up" doesn't name a safe range. identify the tab, headers and cells to leave alone. read the proposed edits first.
  • a closed local app misses the monday check. a run less than 12 hours late runs once on return. older runs skip.

tell it what blank means

tell the bot whether that blank means missing stock or none left. name the columns with formulas too. ask for the source range beside each finding so you can open the row that needs attention.

working from a file dropped in chat? see excel files. that is a different route from a connected spreadsheet.

start the chart with the right transactions

a missing transaction stays missing in a beautiful chart. if the question starts with billing records, read stripe before planning the update.

connect google drive separately for other source files. say which source wins when figures disagree.

a row number beside the finding saves a hunt.

mistakes people make

asking it to clean the whole workbook

name one range and the columns it must leave alone.

assuming blank means zero

say whether blanks mean missing, zero or not applicable.

allowing find and replace on a reading bot

remove it from the exact action list; dusk counts it as a read.

questions

can claude or chatgpt update my google sheet?

yes, through a bot using your chosen ai. it needs the connected account, permission for that write and a clear destination range.

does it ask before changing a cell?

not automatically. cell edits sit outside the send approval rule. include the ask-first line and keep the allowed actions narrow.

can it just tell me which rows look wrong?

yes. keep the result in chat. ask for row numbers and reasons, and tell it to leave source values alone.
