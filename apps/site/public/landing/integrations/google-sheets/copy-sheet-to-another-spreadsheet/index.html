copy one google sheets tab into another spreadsheet

give the meeting its briefing tab without handing over the whole workbook. the bot copies one google sheets tab into an existing destination spreadsheet.

by the Metal team · checked 12 november 2026 · how we made this

give it both file links, the direction and the tab name. the original stays put. the copy is a snapshot, so later source edits won't follow.

copy sheet to another spreadsheet, in plain words

hand over the useful tab without sending the whole workbook. the bot finds the tab from its name and copies it into the destination file. say which link is the source and which is the destination.

the destination must already exist. this action can't choose a new tab name or copy just a few cells. those need separate steps. it's a snapshot: later edits to the source won't follow.

a routine to copy

paste this into a chat with your bot

every other wednesday at 15:10, find this fortnight's dated briefing tab in the research workbook. look in the steering workbook for an existing copy of that briefing.

if a copy exists, stop and tell me. otherwise show both file names and the dated tab here. ask me before copying the complete tab. never copy other tabs or rename anything.
when
alternate wednesdays at 15:10
needs
google sheets read and write; access to the source and permission to add a destination tab

what comes back looks like this (an example)

copy proposal

- source: ivo marsh's research workbook, this fortnight's briefing tab
- destination: willow bend steering

ready for you to approve this direction.

good jobs for it

  • put the agenda where the meeting happens. copy its prepared tab into the existing meeting workbook.
  • start a project from an agreed plan. copy the planning tab from your template file.
  • hand over one report. add the selected reporting tab to the review workbook.
  • experiment away from the original. copy the worksheet into a separate analysis file.

before it runs

Metal counts Copy Sheet to Another Spreadsheet as a change: it alters something in Google Sheets, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Sheets asks for to run it: spreadsheets, drive.file, drive.

how to start

  1. connect both files. the bot needs google sheets read and write, plus access to source and destination.
  2. give both links. say which direction to copy and name the tab.
  3. read the proposal. require your yes before it adds the tab.
  4. inspect the first copy. keep the routine only for fresh dated briefings. pause after a one-time handoff.

limits worth knowing

  • similar tab names are easy to mix up. use the exact one you want.
  • the whole tab goes across. this action has no cell selection. choose another approach for an excerpt.
  • a retry can create another copy. inspect the destination after a timeout before trying again.
  • copies grow apart. later source edits do not update the destination. decide separately whether to copy again.

try it in 2 minutes

  1. open the source and destination spreadsheets
  2. copy their links to the bot
  3. name one tab and ask for a copy proposal
  4. confirm the copy goes from source to destination

two links don't say which way the copy goes.

mistakes people make

expecting the copy to stay current

treat it as a snapshot. later source edits need a separate update.

retrying when the reply is unclear

look in the destination first. the tab may already be there.

before the handoff

  • the source tab is the right dated briefing
  • the destination file already exists
  • the whole tab belongs in that destination
  • there is no existing copy of this briefing

questions

does it copy the whole spreadsheet?

no, just one tab. the other tabs stay in the source file.

can it make a new destination spreadsheet too?

make that file first. use create a google sheet, then give the new file link as the destination.

can i choose the new tab name in the same request?

this copy action cannot name it. renaming needs another allowed action.
