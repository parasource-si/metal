what this discord connection can actually do

find the server behind the invite before sharing the wrong one. a bot can look up your discord profile, list servers, resolve invites and inspect server widgets.

by the Metal team · checked 12 november 2026 · how we made this

schedule the account housekeeping you keep putting off. this toolkit has no channel-message reading or reply action. use it for account and server lookups, rather than conversation summaries.

what a bot can do in Discord

know which servers and accounts you're still connected to. the bot lists your memberships, looks up your profile and finds where an invite points. use that for account housekeeping. conversations inside the servers need a different connection.

actionMetal treats it aswhat you would use it for

Get my guild memberreadshow your membership details for the server you name
Resolve Invitesend: asks firstfind where that invite leads before you pass it on
Get Guild Widgetreadread the widget for the server you are reviewing
Get Guild Templatereadread the server template you want to review
List My Connectionsreadshow the external accounts still linked to your discord
Get my OAuth2 authorizationreadlook up the current authorization when you need to identify the connection

composio, the connection service behind Metal's apps, lists 28 Discord actions (version 20261101_00, read 12 november 20264). Metal treats 20 as reads, 1 as sends and 7 as changes.

only actions starting with a read word (get, list, search) count as reads, so a read-only bot can't call the rest. a send reaches people or moves money, like resolve invite, and waits for your Allow unless you set a daily amount.

connect Discord

  1. open Connected apps in the sidebar.
  2. pick Discord and sign in on Discord's own page, so your password goes to them and never to a bot.
  3. choose which bots may use it, and whether each may only read or may also change things. your bookkeeper doesn't need your Discord.
  4. ask in plain words. reading and drafting happen freely; sending asks you first.

start with your own profile. connect discord, allow this bot to read it, then ask which account it found. name the server or template next.

you sign in on discord's page. your password never goes to the bot.

routines to copy

let it do the account housekeeping you keep postponing. give it your expected accounts and server categories once, in memory notes. these routines compare them with current discord details and return the differences here.

monthly server memberships

on the first monday of each month at 9, list my discord servers. compare them with the community and work categories in your memory notes. show names under community, work and unsure here. ask about anything unclassified. never leave a server or change my account.

first monday each month at 9:00 · server names grouped in dusk chat, with uncertain memberships left for you

linked-account review

every friday at noon, read the external accounts connected to my discord. compare them with the expected-account list in your memory notes. flag differences here. report a failed lookup as a failed lookup, not a change. leave settings alone.

fridays at 12:00 · a comparison with your expected accounts, or a clear lookup failure

server setup review

every tuesday at 11, read the template and widget for the discord server named in your job. compare the returned details with the onboarding checklist in your memory notes. report changes or missing information here. if both lookups succeed and nothing differs, stay quiet. never fill gaps by guessing.

tuesdays at 11:00 · a note about current setup differences, with failed lookups named separately

what it asks you first

keep the account reviews read only. that covers these routines, and you can turn discord off for one bot without affecting the others.

invite resolution is the oddity: dusk classes it as a send. a read-only bot can't use it. with that action allowed, it asks unless you set a daily amount.3

careful with Full access: a bot there with no sending rule can send up to 25 a day without asking. give it Ask every time.3

this toolkit still has no send-message action. granting writes won't add one.

what it cannot do

  • read or search channel conversations. this toolkit cannot retrieve yesterday's discussion to summarise it.
  • reply in channels or direct messages. connecting this toolkit does not place a conversational teammate inside discord.
  • turn a missing widget into a server audit. report what came back and what the bot could not inspect.
  • run while its local computer sleeps. the app and machine must be on. dusk cloud provides a home for scheduled work.

if you wanted several bots talking

put bots in a dusk group when you want them talking together. each keeps its own job and permissions in the group thread. choose who answers there.

for work conversations you want reviewed, look at the slack actions. choose the connection that can read your source.

put the missing lookup in the report

know which account differences need your attention. keep the expected-account list in the bot's memory notes. ask it to name that baseline beside any difference.

if a lookup fails, have it say which one. then you know whether to fix access or investigate a real account change.

ask which profile is connected. the right server list from the wrong account still wastes your morning.

try it in 2 minutes

  1. connect discord for reading
  2. ask which profile is connected
  3. ask it to list your servers
  4. compare one membership with discord itself

does this connection fit your job

  • the task concerns accounts, memberships, invites or server setup
  • you are not relying on channel-message access
  • the expected account or server is clear
  • failed lookups will appear as unknowns

mistakes people make

expecting a channel assistant from a discord connection

use it for account and server lookups. it has no channel-message actions.

reading missing widget data as no change

report the failed lookup. no data means you cannot make the comparison.

questions

can i talk to claude in my discord server through this connection?

no. it provides account, server and application lookups. channel-message reading and sending are absent.

can it summarise messages with my laptop closed?

it cannot read those messages at all. cloud hosting keeps a bot awake; it does not add missing discord actions. local schedules also stop during sleep.

what discord routine is useful without chat access?

review memberships or linked accounts. a server-template check can also help. choose one of those supported lookups rather than asking for a conversation summary.

free on your own computer, with every feature. no account, no card.
