Metal/integrations/google drive

get a portable copy of a google workspace file

take a copy without sharing the live original. a bot can export google docs, sheets, slides and other supported workspace files into a format you choose.

by the Metal team · checked 12 november 2026 · how we made this

give it the file link and say 'pdf' or 'word'. google caps exported content at 10 mb. dusk requires read and write access for this export.

where it helps

  • give an offline editor a docx copy of your google doc
  • take a pdf presentation to a venue
  • make an xlsx copy for someone who uses excel
  • get a plain-text document copy for a separate reading task

the short version

give the editor a word file, or take a pdf to the venue. paste the original's link or ask the bot to find it. name the format you need.

  • docs can become docx or pdf
  • sheets can become xlsx or csv
  • slides can become pptx or pdf
  • drawings also support export

start from workspace content. uploaded photos and pdfs need a different conversion route. open the result before handing it over.

step by step

  1. connect google drive with read and write for export
  2. paste the workspace file link and name the format
  3. ask to see the source title and format before each export if you want a preview
  4. open the returned copy; pause the routine when rehearsals end

every sunday at 7, read the linked google document for northmere choir’s current rehearsal notes. export it as docx only if the notes changed since the last copy. ask me before exporting; show the source title and format. return the file here. report size failures clearly. never share the original, email the copy or change the notes.

what can go wrong

  • 10 mb is the export ceiling. a bigger result can fail rather than return a complete file.
  • formats depend on the source. a slide deck cannot become a spreadsheet.
  • drive storage is broader than workspace export. this action is not a converter for every uploaded file.

permissions and asking first

Metal counts Export Google Workspace file as a change: it alters something in Google Drive, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Drive asks for to run it: drive, drive.file, drive.meet.readonly, drive.readonly.

try it in 2 minutes

  1. connect drive and allow workspace export
  2. paste one google doc link
  3. ask for a pdf copy
  4. open it and look for missing pages or broken layout

say what the recipient needs to do: read a pdf, or edit a word file.

mistakes people make

asking it to convert an uploaded pdf

start from a supported google workspace original.

sending the copy without opening it

open the copy and look at its layout before passing it on.

questions

why does it need write access just to make a copy?

dusk treats export as a change. read only cannot call it. allow this exact action rather than unrelated drive edits.

does exporting give someone access to the original?

you get a copy; the original stays private. export returns file content without changing sharing permissions. sending that copy is a separate job.
