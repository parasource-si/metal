Metal/integrations/google drive

ask ai to upload a file into the right google drive folder

put the approved poster where the printer can find it. give the bot a file up to 5 mb and a google drive folder.

by the Metal team · checked 12 november 2026 · how we made this

it creates a new copy rather than replacing an older file. a bad or missing destination can silently send it to drive's top level. uploads bypass sending approval, so ask for the folder preview before it writes.

where it helps

  • event artwork: put the approved poster pdf in the event folder.
  • a client handover: upload a small signed certificate to the right folder.
  • report delivery: save the bot's report in your reporting folder.
  • project reference: add an image without moving existing files.

the short version

attach the file and name its home. drop it into chat with a clear filename, file type and destination. the bot finds the folder before uploading.

several folders can share a name. use the folder link when names overlap. after the upload, open that folder and the new file together.

step by step

  1. allow the needed actions. connect drive with read and write for uploads and location checks.
  2. provide one file. attach it and ask the bot to find the destination folder.
  3. review the preview. review the name, type, size and folder. tell it to ask first.
  4. open the result. open the file in its actual drive folder. schedule new files from a project folder only after that works.

send this to your bot

paste this into a chat with your bot

every thursday at 1, look in the approved posters folder in the project folder i gave you. find new pdfs that aren't yet in the hollymere exhibition prints folder on google drive. compare each file's size with the 5 mb limit. show its filename, type and proposed drive folder here. ask me before you change anything. upload only the files i choose, then return each saved file and its actual folder. stop if the folder is missing or ambiguous. never replace, delete or upload a second copy.

thursdays at 13:00
needs

jess's approved artwork is ready for the exhibition prints folder.

what can go wrong

  • 5 mb is this action's limit. drive's storage allowance does not make this upload larger.
  • find the existing copy before uploading again. each upload creates another file.

permissions and asking first

Metal counts Upload File as a change: it alters something in Google Drive, and the sending setting does not cover it. a bot you allow only to read can never call it.

the permissions Google Drive asks for to run it: drive, drive.appdata, drive.file.

inputs

inputrequiredwhat it is
file_to_uploadyesFile to upload to Google Drive (max 5MB).
folder_to_upload_tonoOptional ID of the target Google Drive folder; can be obtained using 'Find Folder' or similar actions.

from composio's catalog for Google Drive (action GOOGLEDRIVE_UPLOAD_FILE, read 12 november 20264). your bot fills these in from what you tell it.

try it in 2 minutes

  1. attach a small file
  2. name the drive folder and ask the bot to find it
  3. read the proposed filename and folder link
  4. after uploading, open that folder

give the printer a file in the right folder, not a treasure hunt.

quick checklist

  • the file is within 5 mb
  • the filename and type match the file
  • the destination folder is unambiguous
  • there is no existing copy

mistakes people make

trusting the upload result alone

open the new file and read its folder location.

rerunning the same upload

look for the existing copy first.

questions

why did the upload appear outside my folder?

the folder choice may have failed. a missing or wrong folder can send the file to drive's top level. inspect its actual location.

can it upload the file i drop into dusk chat?

yes, within 5 mb. attach it or drop it in chat. the bot still needs drive write access and the right filename and type.
