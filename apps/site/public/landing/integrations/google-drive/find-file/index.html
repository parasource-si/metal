Metal/integrations/google drive

find a drive file from more than its filename

stop opening five files called final. a bot searches drive by name, type, date or folder and returns names, dates and links.

by the Metal team · checked 12 november 2026 · how we made this

it can cover my drive and shared drives your connected account can open. give it the clues you remember and get a shortlist, with the files left where they are.

where it helps

  • find equipment certificates. limit the search to pdfs in the equipment folder.
  • recover a folder. use the part of its name you remember.
  • collect revised decks. look for presentations changed since the review date.
  • locate a contract copy. name the shared drive that should hold it.

the short version

a pdf, a folder link and a rough date can be enough. the bot searches my drive and shared drives your account can open. results include names, types, dates and viewing links.

it can fetch further matches too. once you have the shortlist, open the contents before choosing the latest contract or treating a certificate as valid.

step by step

  1. leave files untouched. connect drive with read only for this bot.
  2. point at the folder. paste its link and name a file type or date clue.
  3. try the folder once. open a returned link and confirm it points into the folder you meant.
  4. keep up with revisions. change the routine when the folder or reporting dates change.

send this to your bot

paste this into a chat with your bot

on the second friday of each month at 4:30, search the fablecrest equipment folder in drive. find pdfs modified since the previous search.

- finish reading all results
- return each name, modification date and viewing link here
- flag similar certificate names instead of choosing one

never move files or change sharing. do not call a certificate valid without reading it.
when
second friday of the month at 16:30
needs
google drive connected with read only; access to the fablecrest equipment folder

what comes back looks like this (an example)

fablecrest equipment pdfs
workshop-press-certificate.pdf: changed thursday; viewing link
workshop-press-certificate-copy.pdf: changed friday; viewing link
two candidates to open for a validity review.

what can go wrong

  • choose a version by what is inside it. a filename alone cannot tell you which contract is current or approved.
  • want full-text matches in date order? the bot has to sort them after the search.
  • more matches can follow. finish reading them before saying a file is missing.

permissions and asking first

Metal counts Find file as a read: it looks and changes nothing. a bot you allow only to read can use it.

the permissions Google Drive asks for to run it: drive, drive.appdata, drive.file, drive.meet.readonly.

try it in 2 minutes

  1. connect drive with read only
  2. paste a folder link
  3. ask for pdfs changed since a date you choose
  4. open a result and read the contents you need

mistakes people make

searching all drive for "contract"

start with the client folder and file type.

choosing the newest filename

use the modification date and the contents. filenames can mislead.

questions

can it search one shared drive?

yes, name the shared drive. a link helps the bot choose the right one.

what if i have forgotten the filename?

use the clues you have. a folder, file type or date can narrow the list. ask it to flag uncertain matches.
