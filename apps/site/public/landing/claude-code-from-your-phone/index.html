claude code from your phone: three ways in

leave the desk and keep the conversation going from your phone. remote control reaches claude code on your computer. anthropic cloud sessions run elsewhere.

by the Metal team · checked 12 november 2026 · how we made this

dusk lets you text a named bot using claude code. as of 12 november 2026, all three routes exist. pick where the work lives so you know whether the laptop can come with you.

which computer is doing the work?

choose the host that will still be on when you need it. anthropic details are as of 12 november 2026. dusk access depends on which host you pair with.

remote control still needs the machine at your desk

pick up the session you left running at your desk. remote control connects claude.ai/code or the claude ios/android app to claude code on your own machine.1

leave that computer on with the claude process running. after sleep or a lost network, it reconnects when the machine returns; work pauses during the gap.1

as of 12 november 2026, remote control supports pro, max, ultra, team and enterprise. api-key sign-in is not supported. team and enterprise need an owner to enable it.1

choose this for work that belongs on your desk computer. leave it powered and connected before heading out.

cloud sessions leave the laptop out of the job

close the laptop and let a cloud session keep working. anthropic hosts it elsewhere, so you can read or steer it from another device.2

start from the mobile code tab, claude.ai/code, desktop or claude --cloud. usage counts toward your plan limits. as of 12 november 2026, plans include pro, max, ultra, team and eligible enterprise seats.2

try this for a coding session while travelling before renting another machine. repeating work is a separate decision; see the claude schedules guide.

dusk gives the work a named bot

text the same teammate tomorrow, with its memory intact. a Metal bot has a name, a job, its own chats and memory, and the ai you choose.4

choose claude code and dusk runs that official command-line app where the bot lives. you complete the sign-in yourself.6

keep planning and document review as separate jobs, with different memories or ais. changing a bot's ai keeps its chats, files and memory.4

choose dusk for continuing work with a teammate you text. use remote control to reach a particular session.

phone access does not change provider terms

use your own sign-in in the unmodified claude code app. anthropic's legal page, checked on 12 november 2026, permits that end-user setup.7

it also sets conditions for platforms that host claude code.7 read the current terms for your setup. phone access keeps the same subscription rules and provider limits.

pair once, then text it from the couch

scan the code and send your first message from the phone. alternatives include a six-digit code, the nearby wi-fi list or tailscale. no account is needed.3

iphone and android use the paired browser version today. add it to the home screen. store apps are on their way; this browser version sends no notifications.3

your paired computer needs dusk running. settings, remote access, keep this computer awake helps it stay reachable. pair to dusk cloud for access with your own computer off.35

overnight hosting covers that choice. telegram, discord and slack covers separate chat channels.

use the small screen for small decisions

get the next small decision off your desk. ask for two assumptions to revisit in an attached proposal. have the bot leave the file alone. save the whole-document review for a bigger screen.

dusk approval cards can reach your phone. allow apps per bot, read only where enough. for app writes, say 'ask me before you change anything'.8

read the preview before allowing a command or file change.8 if the phone makes it hard to read, wait until you can see it properly.

try it in 2 minutes

  1. keep dusk open on the host computer
  2. scan its phone-pairing code
  3. ask the bot a short question from your phone
  4. see which computer you paired with and leave it awake

before packing the laptop, ask which computer is actually doing the work.

questions

how are people running claude code from their phone?

three routes serve different jobs. as of 12 november 2026, remote control reaches a local session, cloud sessions run remotely, and dusk offers chat with a named bot. the host decides whether your laptop can sleep.123

why does it stop working when i leave my laptop?

the local host paused when you left it. remote control needs the computer and claude process running. dusk paired to that computer needs dusk open too.13

do i need an app store download to pair dusk?

use the paired browser version today. store apps are on their way. add dusk to the home screen and remember that this version has no notifications.3
