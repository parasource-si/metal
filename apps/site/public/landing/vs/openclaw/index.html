openclaw vs Metal: running it day to day

pick the setup you can still manage on a busy monday. openclaw routes agents through a gateway and chat channels; its desktop installers handle the initial pieces.12 dusk puts bots, their jobs and per-bot app access in its own app.67 both support separate agents and scheduled work.

by the Metal team · checked 12 november 2026 · how we made this

decide who handles upkeep, where instructions arrive and how much access the job needs.

the short version

pick openclaw if

  • you want to change the code. its mit license and gateway suit an owner who will operate them.
  • you want chat-app entry points. route agent conversations through whatsapp, telegram or signal.

pick Metal if

  • you want bot settings in one app. manage jobs, chats and permissions from the desktop.
  • you want hosting handled later. dusk cloud gives you that option without maintaining your own server.

from first install to the next morning

choose where instructions arrive and who owns the upkeep. as of 12 november 2026, both support separate agents. their day-to-day setup and controls differ.

the installer is only the first evening

someone still has to maintain the machine. openclaw’s desktop apps install the required pieces. terminal routes need node.js 24 or 26.2

openclaw has no first-party hosted tier. dusk cloud is dusk’s hosted option.312 decide who owns updates and restarts before relying on an early-morning job.

openclaw without setup covers the install and hosting choices. an easy install and an easy month afterwards are different questions.

approval has three separate parts

put a boundary around each kind of work. dusk separates command and file approvals, app access and sending.

  • commands and files: choose an approval level
  • apps: allow reads, reads and writes, or specific actions
  • sends: ask every time, or a daily amount11

read-only app access blocks changes before they reach the app.7 ordinary writes, such as moving a meeting, do not automatically pause. keep reads only or say “ask me before you change anything”.

openclaw publishes security advisories, including critical flaws.10 find your version and read the fixes it needs. the openclaw safety guide goes closer.

make the first morning job easy to inspect

start with a folder and a question you can answer yourself. try: “every weekday at 9, read this project folder. list decisions still needing my answer. leave files unchanged.”

watch the first runs. widen access only when the job needs it.

dusk shows a card with the schedule and next runs. edit, pause and undo live there too. a local run missed by less than 12 hours runs once on return; older runs are skipped.9

agents with a closed laptop covers where that job should live. openclaw versus hermes compares the open projects’ routing, subagents and cloud choices.

how we checked

we compare setup and controls, not a security score. Metal is based on Dusk Bot. we read openclaw’s docs and github advisories on 12 november 2026 alongside dusk’s controls.

we did not run identical jobs, test reliability or try to break either product. published flaws need context: affected versions, fixes and what your installation exposes.

pick the system you can supervise on a busy day, when you have no patience for setup.

try it in 2 minutes

  1. choose one folder with harmless trial files
  2. ask for its unresolved questions with no edits
  3. compare the answer with those files
  4. choose hosting only if the job needs to run while you are away

before making either setup part of your day

  • someone owns the machine’s upkeep
  • only required files and apps are within reach
  • you know where approval questions arrive
  • the schedule survives the way you use your laptop

mistakes people make

calling an advisory count a security verdict

find the affected versions, their fixes and what your installation exposes.

assuming sending controls pause app edits

limit app access separately and put ask-before-changing in the job.

questions

do i need docker or a terminal for openclaw?

neither is required for the desktop route. its apps install the pieces. terminal installs need node.js 24 or 26; the default route needs no docker.2

is openclaw free or paid?

the mit software is free as of 12 november 2026. you pay for ai usage and any server.3 dusk is source-available rather than open source, and work needs a license.14

does Metal ask before every change?

app edits need their own boundary.11 read-only access blocks changes before they reach the app. ordinary writes do not automatically ask. command approvals and sending use separate settings.711

free on your own computer, with every feature. no account, no card.
