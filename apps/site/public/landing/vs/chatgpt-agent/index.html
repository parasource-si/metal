chatgpt agent is gone: chatgpt work vs Metal

pick the app that makes your next handoff easier. as of 12 november 2026, openai says agent is no longer available.1 work replaces it for longer tasks and finished deliverables.

by the Metal team · checked 12 november 2026 · how we made this

web and phone run in the cloud; desktop can work locally too.2 dusk gives named bots their own memory and ai choices. compare the roles you need and the usage bills.

the short version

pick chatgpt work if

  • finish multi-step tasks inside chatgpt. keep openai models and the work together.
  • share one usage pool with codex. that fits how you already budget.

pick Metal if

  • keep roles apart. each bot has its own memory and chats.
  • choose ai per role and where bots live. use your computer, server or dusk cloud.

put the task where its files live

work can reach local files from desktop. openai points former agent users to work.1 choose it inside chatgpt.3 the cowork comparison covers another changing product.

web and phone tasks run in the cloud. desktop can use local files, apps and a browser.2 find where your file lives, then see which plugins work where you start the task.

your schedule count isn't your usage budget

work and codex spend from shared usage. count both when you plan the month.4 an active schedule slot doesn't tell you how many runs your plan can finish. timing controls and active-task limits vary by plan.5

dusk separates hosting from ai usage. your provider bills the ai, and a bot tells you when that plan runs out.811

read the task guide for schedule caps and the cost guide for the full bill.

test a handoff you can judge

find out how much correcting the handoff takes. attach short notes. ask for agreed points, open questions and claims the notes don't support. compare the result with the original.

dusk can give preparation and review separate jobs, chats and memory.11 try attached files first. if you connect apps later, keep the reviewer read only so it can read the work without changing it.1213

questions

does chatgpt work run on my own computer?

desktop work can run locally. it can use local files, apps and a browser. web and mobile work run in openai's cloud, as of 12 november 2026.2

can i use chatgpt agent on my iphone?

use its replacement, work. it supports ios, android, web and desktop. phone and web tasks run in the cloud.2 old agent guides don't tell you current work quotas.
