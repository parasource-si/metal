chatgpt agent is gone: compare work with a team of bots

try work before you leave chatgpt over agent mode. as of 12 november 2026, openai says agent is no longer available.1 work handles longer, multi-step tasks and finished deliverables instead.

by the Metal team · checked 12 november 2026 · how we made this

it can also run locally through the desktop app. dusk suits you if separate bots, their own memory and different ai choices matter more than staying inside chatgpt.

the short version

pick chatgpt work if

  • stay inside chatgpt. choose work without organising another bot app.
  • keep openai models and plan usage together. one product may be enough.
  • use web, phone or desktop. desktop work also has a local option.

pick Metal if

  • give each helper a job. named bots keep their own chats and memory.
  • change the ai per bot. its chats, files and memory stay put.
  • bring bots together. use a group thread with a leader or mentions.

your old agent guide might be the problem

you don't need another app just because the button disappeared. openai's help article says agent is no longer available and points to work.1 start with the current work instructions.2

an old review may accurately describe a retired feature. look for its date and whether it covers work before paying for a plan. use work versus dusk when those are your final two choices.

take the same document into either desktop app

you can try the document job on the machine you already own. web and mobile run in the cloud. the desktop app can work locally with files, apps and a browser.3

dusk's difference is the team you keep: separate jobs, chats and memory. each bot can hold several threads. switching its ai keeps those chats, files and notes.9 in a group chat, each keeps its own ai and permissions.13

try an attached planning document first. ask for a decision brief with evidence and open questions.12 read it beside the source.

count shared usage before buying

work and codex draw from shared usage. openai groups their pricing, credits and limits together.4 openai doesn't give a fixed work task count per plan. include codex use when you budget.

as of 12 november 2026, plus costs $20 monthly. pro tiers cost $100, $200 or $500 monthly. local prices can differ.56 dusk cloud hosting and ai usage are separate bills.810

for repeat jobs, read the scheduled tasks guide. dusk routines need the app open and computer awake locally; cloud runs them on time.14 check your ai provider's current terms before relying on a sign-in.

questions

what happened to chatgpt agent mode?

openai points you to work now. as of 12 november 2026, its help article says agent is no longer available. work replaces it for longer, multi-step tasks and finished deliverables.1

can i use the replacement on my iphone?

yes. work supports ios and android. it also has web, macos and windows apps. phone and web tasks run in the cloud; desktop can work locally.3

how many work tasks do i get with plus or pro?

budget for work and codex together. they share usage, pricing and credits. openai doesn't give a fixed task count per plan; read the current shared limits before buying.4

free on your own computer, with every feature. no account, no card.
