how to run claude code 24/7

the 7am brief won't arrive from a laptop that went to sleep at midnight. a Metal bot using claude code needs an awake computer and open app.

by the Metal team · checked 12 november 2026 · how we made this

your server or dusk cloud keeps it available overnight, within ai limits and any human questions. as of 12 november 2026, anthropic also offers cloud sessions and scheduled tasks. compare those before buying another host.

three homes for a Metal

hosting keeps the machine on, not the ai allowance topped up. these dusk prices reflect 12 november 2026. server rental and ai usage have their own bills.

give overnight work a finish

give the overnight job a finish you want to wake up to. for a one-off: read these files, write the summary, stop. for a routine: name fresh inputs, a time and where the answer goes.

dusk bots keep several threads. steer a working bot with another message. if the ai plan runs out, it tells you. wait for the reset or switch ai; chats, files and memory stay.5

24/7 hosting uses your existing ai allowance. the laptop-closed guide also covers spare computers.

try the laptop while you can watch

test the job before trusting it with a deadline. leave dusk open and the laptop awake. keep this computer awake under settings, remote access helps a paired phone reach it.6

local routines miss their start during sleep or while dusk is closed:

  • less than 12 hours late: one catch-up run when you return
  • older: skipped7

try a routine that reads current files: "each weekday at 7, read this project's planning folder. list open decisions here. change no files." watch a run before relying on it.

rent a server if you want the upkeep

cheap hosting still gives you a computer to maintain. dusk's own-server setup needs:3

  • ubuntu 22.04 or 24.04
  • at least 2 gb memory
  • root or sudo access

paste the line the app gives you; setup takes about ten minutes. no domain or open ports. app and server use a relay sealed with a key only they hold.

use a fresh server. updates, backups and hosting remain your job. compare the quote and your time in the cost calculator.

use dusk cloud when the laptop needs to sleep

let the laptop sleep without taking the morning brief with it. pick a plan and sign in under settings, dusk cloud. the welcome moves chats, memory and routines with your bots. the machine is yours, not shared; dusk makes daily backups.1

plus keeps a good amount of bot desktops awake; pro is for heavy workloads. pair your phone to that cloud computer and reach the bots with your laptop off.6

the phone guide separates Metal chat from anthropic's remote control. the phone reaches the work running elsewhere.

read anthropic’s current rules too

pick the permitted access route before leaving it running overnight. as of 12 november 2026, anthropic describes personal sign-in to unmodified claude code, including on hosted platforms.8

its conditions include:

  • run the app as anthropic publishes it
  • leave its sign-in methods available
  • meet the commercial hosting terms
  • developers cannot offer claude.ai login or handle its sign-ins for others

those conditions do not rule on dusk or another app.

anthropic's consumer terms restrict automated or non-human access except with an api key or permission.11 its login help reserves usage-credit billing for certain third-party tools.12 for unattended work, the terms name the api-key route. read the current terms before choosing.

also compare anthropic's own hosting: cloud sessions continue with the laptop closed, and cloud scheduled tasks repeat saved configurations.910 if they fit, you may not need another host. the scheduler guide explains cloud tasks, local tasks and loops in an open session.

the right overnight job ends. it does not need to look busy until you wake.

try it in 2 minutes

  1. choose one overnight job with a clear finish
  2. run it once while you watch on an awake computer
  3. read the result and ai usage before scheduling it

quick checklist

  • the next run reads current app records or files
  • the host stays on when my laptop sleeps
  • the ai plan or api budget covers the work
  • the access method fits current provider terms
  • questions and approvals have a route back to me

mistakes people make

giving it a vague all-night instruction

name the input, output and stopping point.

buying hosting before testing anthropic's cloud option

compare the existing cloud session or schedule with your actual job.

expecting cloud to remove provider limits

watch ai usage. the host bill buys no extra ai allowance.

questions

how do you run claude code unattended overnight?

start with a task that ends and a route for questions. use ask for approval for commands and file edits, and read-only apps for reading.4 anthropic's terms name api keys for automated access unless it permits another route. read the current terms first.11

will dusk cloud remove claude limits?

buy more ai allowance separately. cloud buys the machine. dusk's docs suggest a bigger ai plan or api key for heavy round-the-clock use.1

can i answer an overnight approval from my phone?

yes, through a paired phone. a laptop pairing needs the laptop on. cloud pairing works with it off. today's phone browser sends no notifications, so open it to check.46
